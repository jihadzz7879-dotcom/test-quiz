پسیارێن تاقیكرنا عەمەلی یا C# (سلاید ٣ هەتا ٢٢)

١٠٠ پسیار ب ئینگلیزی + مانایا وان ب بادینی + كۆدێ دروست یێ C# و ئەنجام (ب تەنێ جۆرێن: int, long, float, double, bool, char, string و هەتا &&, ||, !)

تێبینی بۆ تاقیكرنا سوبەهی: د ناڤ كۆدێ C# دا، هەمی پسیار ب شێوەیێ كۆدێ ناڤ static void Main(string[] args) هاتینە نڤیسین دا راستەوخۆ بكاربی د ناڤ Visual Studio یان كۆمپیوتەرێ دا تاقی بكەی. بیر نەكە: float پێتڤی ب پاشگرێ f هەیە، char ب ' ' و string ب " " دهێتە نڤیسین!

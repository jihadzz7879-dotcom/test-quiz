سلاید ٢ (Slide 2) What is a Computer?
کۆمپیوتەر چییە؟
📌 کورتیا سلایدی: کۆمپیوتەر ئامیرەکە داتایان وەردگریت (Input)، پرۆسێس دکەت (Process)، هەلدگریت (Store)، و ئەنجامی ددەتە مە (Output). ب سیستەمێ دوانی (Binary: تەنها 0 و 1) کار دکەت و د زانست، خویندن، بازرگانی و سەرگەرمیێ دا رۆلەکێ مەزن هەیە.

📖 شروڤەکرنا سلایدێ ب بادینی:

• A computer is a machine that can store and process information.
کۆمپیوتەر ئامیرەکە (machine) دشێت زانیاریان هەلبگریت (store) و پرۆسێس/کار ل سەر بکەت (process).
• It takes data as input, processes it, and provides the result as output.
داتایان وەردگریت وەک داخلکرن (input)، کار ل سەر دکەت (processes)، و ئەنجامی (result) وەک دەرئێخستن (output) ددەتە مە.
• Most computers rely on a binary system, which uses two variables, 0 and 1, to complete tasks such as storing data, calculating algorithms, and displaying information.
زۆربەیا کۆمپیوتەران پشت ب سیستەمێ دوانی (binary system) د بەستن، کو تەنها دوو گۆڕاو (two variables) ب کار دئینیت ئەویش (0 و 1) نە، بۆ تمامکرنا کارێن وەک هەلگرتنا داتایان، حیسابکرنا ئەلگۆریتمان، و نیشاندانا زانیاریان.
• Due to these qualities, the computer plays a crucial role in science, education, business, entertainment, and many other fields in today's era.
ژ بەر ئەڤان تایبەتمەندیان، کۆمپیوتەر د سەردەمێ ئەڤرۆ دا رۆلەکێ گرنگ د بوارێن زانست (science)، پەروەردە (education)، بازرگانی (business)، سەرگەرمی و یاری (entertainment) دا دگێڕیت.

🔑 پەیڤێن کلیل یێن سلاید ٢ (گەلەک گرنگن بۆ ئەزموونێ!):

Machine = ئامیر / ماکینە
Store = هەلگرتن / خەزنکرن
Process = پرۆسێسکرن
Input / Output = داخلکرن / دەرئێخستن
Binary system = سیستەمێ دوانی (0 و 1)
Science / Education = زانست / خویندن
Business / Entertainment = بازرگانی / سەرگەرمی

سلاید ٣ (Slide 3) How Computer Process Data
کۆمپیوتەر چەوا داتایان پرۆسێس دکەت؟
📌 کورتیا سلایدی: پرۆسێسکرنا داتایان ب ٤ پێنگاڤێن ل دویڤ ئێک دچیت: ١. داخلکرن (Input: کیبۆرد، ماوس، سێنسەر)، ٢. پرۆسێسکرن (Processing: ب ڕێکا CPU)، ٣. هەلگرتن (Storage: کاتی د RAM دا و درێژخایەن د Hard Drive یان SSD دا)، ٤. دەرئێخستن (Output: شاشە، پرینتەر، سپیکەر).

📖 شروڤەکرنا سلایدێ ب بادینی:

• Input: Data is entered into the computer through input devices such as keyboards, mice, or sensors.
١. داخلکرن (Input): داتا دهێنە ناڤ کۆمپیوتەری ب ڕێکا ئامیرێن داخلکرنێ وەک: کیبۆرد (keyboards)، ماوس (mice)، یان هەستەوەر (sensors).
• Processing: The CPU (Central Processing Unit) processes the data. It performs arithmetic, logic, and control operations based on the instructions provided by software.
٢. پرۆسێسکرن (Processing): یەکەیا ناوەندی یا پرۆسێسکرنێ CPU (مێشکێ کۆمپیوتەری) داتایان پرۆسێس دکەت. کارێن ژمێریاری (arithmetic)، لۆژیکی (logic)، و کۆنترۆلێ (control) دکەت ل سەر بنەمایێ ڕێنمایێن پرۆگرامی (software).
• Storage: Data is temporarily stored in RAM (Random Access Memory) while being processed. Long-term storage occurs in devices like hard drives or SSDs.
٣. هەلگرتن (Storage): داتا ب شێوەیەکێ کاتی (temporarily) د ناڤ RAM دا دهێنە هەلگرتن دەمێ دهێنە پرۆسێسکرن. بەلێ هەلگرتنا درێژخایەن (long-term) د ناڤ Hard drives یان SSDs دا چێدبیت.
• Output: Processed data is then sent to output devices such as monitors, printers, or speakers for users to access.
٤. دەرئێخستن (Output): داتایێن پرۆسێسکری دهێنە فرێکرن بۆ ئامیرێن دەرئێخستنێ وەک: شاشە (monitors)، چاپکەر (printers)، یان بڵندگۆ (speakers) دا بکارهێنەر ببینن و بکاربینن.

🔑 پەیڤێن کلیل یێن سلاید ٣:

Input devices = keyboards, mice, sensors
Output devices = monitors, printers, speakers
CPU = Central Processing Unit
RAM = Random Access Memory (کاتی)
Temporarily = ب شێوەیێ کاتی (RAM)
Long-term = درێژخایەن (Hard drive / SSD)

سلاید ٤ (Slide 4) How Computer Process Data (Flowchart)
نەخشێ ڕەوتا پرۆسێسکرنا داتایان د کۆمپیوتەری دا
📌 کورتیا سلایدی: ئەڤ سلایدە وێنە و نەخشێ پێنگاڤێن پرۆسێسکرنا داتایانە: ژ داتایێن خاڤ (Raw Data) دەستپێدکەت -> دگوهۆڕیت بۆ 0 و 1 -> دچیتە د ناڤ CPU دا (ALU + Control Unit) و ب شێوەیێ کاتی د RAM دا دمینیت -> وەک زانیاریا پرۆسێسکری (Data Output) دەردکەڤیت -> ئەگەر تە بڤێت خەزن بکەی (Save Result - Optional) -> دوماهی.
1. START (دەستپێک)
⬇
2. DATA INPUT (Raw Data) - داتایێن خاڤ (کیبۆرد / ماوس)
⬇
3. CONVERSION TO BOOLEAN BINARY SYSTEM (0, 1) - گوهۆڕین بۆ 0 و 1
⬇
4. PROCESSING WITHIN CPU: [ALU ⟷ Control Unit]
(هەروەسا پەیوەندی دگەل RAM Temporary Storage هەیە)
⬇
5. DATA OUTPUT (Processed Information) - زانیاریێن پرۆسێسکری (شاشە)
⬇
6. SAVE RESULT (Optional) - پاشکەفتکرنا ئەنجامی (ئارەزوومەندانە)
⬇
7. END (دوماهی)

📖 خالێن گرنگ یێن ناڤ وێنێ سلاید ٤ ب بادینی:

DATA INPUT (Raw Data)
ئەو داتایێن ب ڕێکا کیبۆرد و ماوسی دچنە ژوور ناڤێ وان Raw Data (داتایێن خاڤ) یە، ئانکو هێشتا چ کار ل سەر نەهاتییە کرن.
CONVERSION TO BOOLEAN BINARY SYSTEM (0, 1)
پشتی داخلکرنێ، کۆمپیوتەر داتایان دگوهۆڕیت بۆ زمانێ خۆ (0 و 1) کو پێ دبێژن Boolean Binary System.
PROCESSING WITHIN CPU: Arithmetic Logic Unit (ALU) & Control Unit
د ناڤ مێشکێ کۆمپیوتەری دا (CPU) دوو بەشێن سەرەکی هەنە: ALU (یەکەیا ژمێریاری و لۆژیکی - کارێ حیساباتێ دکەت) و Control Unit (یەکەیا کۆنترۆلێ - کاران ڕێکدئێخیت). و ل بن وان RAM (Temporary Storage) هەیە بۆ هەلگرتنا کاتی.
DATA OUTPUT (Processed Information) & SAVE RESULT (Optional)
پشتی پرۆسێسکرنێ ناڤێ داتایان دبیتە Processed Information (زانیاریێن پرۆسێسکری) و ل سەر شاشێ دەردکەڤیت. پاش خەزنکرنا ئەنجامی (Save Result) Optional (ئارەزوومەندانەیە).

🔑 پەیڤێن کلیل یێن سلاید ٤:

Raw Data = داتایێن خاڤ (ل دەستپێکێ)
Processed Information = زانیاریێن پرۆسێسکری
ALU = Arithmetic Logic Unit
Control Unit = یەکەیا کۆنترۆلێ (د ناڤ CPU)
Temporary Storage = هەلگرتنا کاتی (RAM)
Optional = ئارەزوومەندانە (Save Result)

سلاید ٥ (Slide 5) Main Features of Computer (Advantages)
تایبەتمەندیێن سەرەکی یێن کۆمپیوتەری (باشیێن کۆمپیوتەری)
📌 کورتیا سلایدی: کۆمپیوتەر ٥ تایبەتمەندیێن سەرەکی (باشی) هەنە کو گەلەک د ئەزموونێ دا دهێن: ١. لەزاتی (Speed)، ٢. دروستی (Accuracy)، ٣. هەلگرتن (Storage)، ٤. خۆکاری (Automation)، ٥. فرەکاری (Versatility).

📖 شروڤەکرنا سلایدێ ب بادینی (ئەڤ ٥ خالە وەک ناڤێ خۆ ژبەر بکە!):

1. Speed
لەزاتی (خێرایی): کاران ب لەزاتییەکا ئێکجار زۆر دکەت.
2. Accuracy
دروستی (هویربینی): بێ خەلەتی و ١٠٠٪ دروست کار دکەت.
3. Storage
هەلگرتن (خەزنکرن): دشێت بڕەکا زۆر مەزن یا داتایان هەلبگریت.
4. Automation
خۆکاری (ئۆتۆماتیک): پشتی ڕێکخستنێ ب خۆ کاران ئەنجام ددەت.
5. Versatility
فرەکاری (گەلەک-کار): دشێت بۆ گەلەک کارێن جودا جودا بهێتە بکارئینان.

🔑 پەیڤێن کلیل یێن سلاید ٥:

Features / Advantages = تایبەتمەندی / باشی
Speed = لەزاتی
Accuracy = دروستی
Storage = هەلگرتن
Automation = خۆکاری
Versatility = فرەکاری

📌 کورتیا سلایدی: لەزاتی (Speed): کۆمپیوتەر ب ملیۆنان ڕێنمایان د چرکەیەکێ دا پرۆسێس دکەت و ژ مرۆڤان گەلەک زویتر کار دکەت. دروستی (Accuracy): بێ خەلەتی کار دکەت و ١٠٠٪ ئەنجامێ دروست ددەت ئەگەر داخلکرن و پرۆگرام د دروست بن.

📖 شروڤەکرنا سلایدێ ب بادینی:

1- Speed: Computers perform calculations and tasks very quickly. They can process millions of instructions in seconds. Compared to humans, computers complete large tasks in much less time.
١. لەزاتی (Speed): کۆمپیوتەر حیسابات و کاران گەلەک ب زوی دکەن. دشێن ملیۆنان ڕێنمایان د چرکەیان دا (millions of instructions in seconds) پرۆسێس بکەن. ب بەراورد دگەل مرۆڤان، کارێن مەزن د دەمەکێ گەلەک کێمتر دا تمام دکەن.
2- Accuracy: Computers work free from errors. If the input and program are correct, there is no mistake in the output. It provides 100% accuracy in mathematical and logical operations.
٢. دروستی (Accuracy): کۆمپیوتەر بێ خەلەتی (free from errors) کار دکەن. ئەگەر داخلکرن (input) و پرۆگرام (program) د دروست بن، چ خەلەتی د ئەنجامی (output) دا نینە. ١٠٠٪ دروستی د کارێن بیرکاری (mathematical) و لۆژیکی (logical) دا ددەت.

🔑 پەیڤێن کلیل یێن سلاید ٦:

Millions of instructions = ملیۆنان ڕێنما
In seconds = د چرکەیان دا
Free from errors = بێ خەلەتی
100% accuracy = ١٠٠٪ دروستی
No mistake = بێ شاشی

سلاید ٧ (Slide 7) Main Features: 3-Storage Capacity, 4-Automation, 5-Versatility
تایبەتمەندیێن ٣، ٤ و ٥: شیانا هەلگرتنێ، خۆکاری و فرەکاری
📌 کورتیا سلایدی: ٣. شیانا هەلگرتنێ (Storage Capacity): بڕەکا مەزن یا داتایان ل سەر هارد دیسک، SSD، فلاش (pen drive) و عەور (cloud storage) بۆ دەمەکێ درێژ ب سەلامەتی هەلدگریت. ٤. خۆکاری (Automation): ئەنجامدانا کاران ب خۆ ب ڕێکا پرۆگرامان. ٥. فرەکاری (Versatility): بکارئینان بۆ گەلەک کارێن جودا.

📖 شروڤەکرنا سلایدێ ب بادینی:

3- Storage Capacity: Computers have the ability to store large amounts of data. Data can be stored using hard disks, SSDs, pen drives, cloud storage, etc. Data is safely kept for a long time and can be accessed easily when needed.
٣. شیانا هەلگرتنێ (Storage Capacity): کۆمپیوتەر شیانا هەلگرتنا بڕەکا مەزن یا داتایان هەیە. داتا ل سەر hard disks، SSDs، pen drives (فلاش میمۆری)، cloud storage (ئینتەرنێت) دهێنە هەلگرتن. داتا بۆ دەمەکێ درێژ ب سەلامەتی دمینن و ب سادەهی دەمێ پێدڤی دبیت دهێنە ڤەکرن.
4- Automation: The ability to perform tasks automatically through programs.
٤. خۆکاری (Automation): شیانا ئەنجامدانا کاران ب شێوەیەکێ ئۆتۆماتیکی (ب خۆ) ب ڕێکا پرۆگرامان.
5- Versatility: It can be used for various tasks.
٥. فرەکاری (Versatility): دشێت بۆ گەلەک کارێن جودا (various tasks) بهێتە بکارئینان (وەک نڤیسین، یاری، حیسابات، دیزاین).

🔑 پەیڤێن کلیل یێن سلاید ٧:

Large amounts of data = بڕەکا مەزن یا داتایان
Pen drives = فلاش میمۆری
Cloud storage = هەلگرتنا سەر ئینتەرنێتێ
Automation = automatically through programs
Versatility = various tasks (کارێن جودا)

زمانێ C# چییە؟ (What is C#)

چوار خالێن سەرەکی د ڤێ سلایدێ دا هەنە کو گەلەک جاران ل ئەزموونا تیۆری دهێن:

  • خواندن (Pronunciation): ب گۆتنا سلایدێ، C# دهێتە خواندن وەک "C-Sharp or C-Hash". (د ئەزموونێ دا هەردوو ناڤان بزانە چونکی سلاید وەسا دبێژیت!).
  • جۆر و دروستکەر: زمانەکێ پرۆگرامسازی یێ تەنی-تەوەرە (Object-Oriented Programming - OOP)، ژ لایێ کۆمپانیا مایکرۆسۆفت (Microsoft) ڤە هاتیە دروستکرن، و ل سەر .NET Framework کار دکەت.
  • ڕەگ و ڕیشا وی: ژ خێزانا زمانێ C یە، و گەلەک نێزیکی زمانێن بەرنیاسێن وەک C++ و Java یە.
  • سالا دەرکەفتنێ: ئێکەم ڤێرژن (First version) ل سالا 2002 هاتە بەلاڤکرن.
تێبینیا ئەزموونێ: جوداهیێ د ناڤبەرا کۆمپانیا دروستکەر (Microsoft)، ژینگەها کارکرنێ (.NET Framework)، و سالا ئێکەم ڤێرژن (2002) دا ژبەر بکە!

بۆچی C# دهێتە بکارئینان؟ (Why Use C#?)

پێنج ئەگەرێن سەرەکی کو C# کرییە زمانەکێ گەلەک ب ناڤ و دەنگ:

  • ئێک ژ زمانێن پرۆگرامسازی یێن هەرە بەرنیاسە ل جیهانێ (Most popular).
  • فێربوونا وی یا ب ساناهی یە و بکارئینانا وی یا سادەیە (Easy to learn & simple to use).
  • پشتەڤانیەکا مەزن یا جڤاکێ پرۆگرامسازان هەیە (Huge community support).
  • زمانەکێ Object-Oriented یە: ئەڤە ژی پێکهاتەکا رۆهن (Clear structure) ددەتە پرۆگرامان و ڕێکێ ددەت کۆد دووبارە بهێتە بکارئینان (Code reuse)، کو ئەڤە تێچوونا گەشەپێدانێ کێم دکەت (Lowering development costs).
  • چونکی نێزیکی C, C++ و Java یە، ب ساناهی یە بۆ پرۆگرامسازان ژ وان زمانان بهێنە سەر C# یان بەروڤاژی (Switch easily).

پێکهاتا گشتی یا C# (C# General Syntax)

هەر پرۆگرامەکێ سادە یێ C# ژ ڤان پشکێن سەرەکی پێک دهێت:

using System;                 // ١. هاوردەکرنا کتابخانان (Import libraries)

namespace test                // ٢. ناڤێ بۆشاییا ناڤان (NameSpace: test)
{
    class Program             // ٣. ناڤێ کلاسی (className: Program)
    {
        static void Main(string[] args)   // ٤. مێثۆدا سەرەکی (Main Method)
        {
            C# statements...  // ٥. فەرمانێن C# ل ڤێرێ دهێنە نڤیسین
        }
    }
}                             // ٦. دوماهیکا NameSpace
تێبینی: باش تەماشەی ڕێزبەندیێ بکە: ل دەستپێکێ using، پاشی namespace، د ناڤ دا class، و د ناڤ کلاسی دا Main هەیە!

ڕوونکرنا پێکهاتا گشتی (C# General Syntax)

د ڤێ سلایدێ دا، رامانا هەر پشکەکا کۆدێ سەری ب دروستی هاتیە دیارکرن:

  • using System: رامانا وێ ئەوە کو ئەم دشێین وان کلاسان بکاربینین یێن د ناڤ System namespace دا هەنە (بۆ نموونە کلاسێ Console).
  • namespace: بۆ رێکخستنا کۆدی دهێتە بکارئینان، و وەک قووتیکەکێ (Container) یە بۆ کلاسان و namespaceێن دی.
  • کەوانێن لوول {} (Curly braces): دەستپێک و دوماهیکا بلۆکەکێ کۆدی (Block of code) دیار دکەن.
  • class: قووتیکەکە (Container) بۆ داتا و مێثۆدان کو کاراییێ (Functionality) ددەتە پرۆگرامێ تە. هەر دێرەکا کۆدی کو د C# دا کار بکەت، دڤێت د ناڤ classەکێ دا بیت! (د نموونێ دا ناڤێ کلاسی Program بوو).
  • مێثۆدا Main: تشتەکێ دی یە کو هەردەم د پرۆگرامێ C# دا دیار دبیت. هەر کۆدەکێ د ناڤ کەوانێن {} یێن Main دا بیت دێ جێبەجێ بیت (Executed).

نموونا ئێکێ (First Example)

ئەڤە ئێکەم پرۆگرامێ تەمامێ چاپکرنا پەیڤا Hello World! یە د C# دا:

using System;

namespace test
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World!");
        }
    }
}

ئەنجام (Output):

Hello World!

ل ڤێرێ Console کلاسەکە ژ System namespace، و WriteLine() مێثۆدەکە کو دەقێ ناڤ جووت کۆتێشنان "..." چاپ دکەت.

تێبینیێن گشتی (General Notes)

ئەڤ ٥ تێبینیە گەلەک گرنگن بۆ پرسیارێن راست و خەلەت و دیتنا خەلەتیان د ئەزموونێ دا:

  • C# هەستیارە بۆ پیتێن گر و هویر (Case Sensitive): پیتا هویر a جودایە ژ پیتا گر A.
  • خال و بۆر ; (Semicolon): هەمی فەرمان و دەربڕین (Statements and expressions) دڤێت ب سێمیکۆلۆن ; بدوماهی بهێن.
  • دەستپێکا جێبەجێکرنێ: پرۆگرام ژ مێثۆدا Main دەست ب کارکرنێ دکەت.
  • جوداهی دگەل Java: بەرۆڤاژی زمانێ Java، د C# دا ناڤێ فایلێ پرۆگرامی دشێت جودا بیت ژ ناڤێ کلاسی.
  • Console.ReadKey(): دشێت ل دوماهیکا کۆدی بهێتە زێدەکرن. ئەڤە دێ وەل پرۆگرامی کەت چاڤەرێی لێدانا کلیلەکێ (Key press) بکەت و ناهێلیت شاشە بلەز ڤەبیت و دەمێ ژ Visual Studio .NET دهێتە ڤەکرن بێی راوەستان دابخرێت.

چاپکرن ب WriteLine یان Write

بۆ چاپکرنا تشتان ل سەر شاشێ، د C# دا دوو مێثۆدێن سەرەکی هەنە:

  • WriteLine(): پشتی چاپکرنا هەر دەقەکی، دچیتە سەر دێرەکا نوو (New line).
  • Write(): چاپ دکەت ل سەر هەمان دێر (Same line) و ناچیتە دێرا نوو.

نموونە:

Console.WriteLine("Hello World!");
Console.WriteLine("I will print on a new line.");
Console.Write("Hello World! ");
Console.Write("I will print on the same line.");

ئەنجام (Result):

Hello World!
I will print on a new line.
Hello World! I will print on the same line.
گەلەک هشیار بە! دێرا دووێ ب WriteLine بوو، لەوما دێرا سێیێ ل سەر دێرەکا نوو دەست پێ کر. بەلێ دێرا سێیێ ب Write بوو، لەوما دێرا چوارێ هاتە تەنشتا وێ ل سەر هەمان دێر!

کۆمێنت د C# دا (C# Comments)

بۆچی کۆمێنت دهێنە بکارئینان؟

  • بۆ ڕوونکرنا کۆدێ C# و خواندنا وی ب ساناهیتر (More readable).
  • هەروەسا بۆ رێگریکرنێ ل جێبەجێبوونا کۆدی دەمێ تاقیکرنا کۆدەکێ جێگر (Testing alternative code). کۆمپایلەر کۆمێنتان ناخوینیت و چاپ ناکەت!

دوو جۆرێن کۆمێنتان هەنە:

  • کۆمێنتا ئێک دێری (Single-line): ب دوو خەتێن لار // دەست پێ دکەت.
  • کۆمێنتا فرە-دێری (Multi-line): ب /* دەست پێ دکەت و ب */ بدوماهی دهێت.
// This is a comment
Console.WriteLine("Hello World!"); // This is another comment

/* The code below will print the words Hello World to the
screen, and it is amazing */
Console.WriteLine("Hello World!");

گۆڕاوەکان و جۆرێن داتایان (C# Variables)

گۆڕاو (Variables): قووتیکن (Containers) بۆ هەلگرتنا بەهایێن داتایان (Storing data values). د C# دا جۆرێن جودا یێن گۆڕاوان هەنە کو ب پەیڤێن پاراستی (Keywords) دهێنە دیارکرن:

جۆر (Type) چ هەلدگریت؟ نموونە تێبینیا گرنگ
int ژمارێن تەمام (Whole numbers) بێی پۆینت 123 یان -123 نابیت پۆینت تێدا بیت
double ژمارێن کەرتی / ب پۆینت (Floating point) 19.99 یان -19.99 ژمارێن ب پۆینت
char ئێک پیت یان هێما (Single character) 'a' یان 'B' د ناڤ ئێک کۆتێشن ' ' دا یە
string دەق و ڕستە (Text) "Hello World" د ناڤ جووت کۆتێشن " " دا یە
bool دوو حالەت: راست یان خەلەت true یان false بێی کۆتێشن دهێنە نڤیسین

چێکرنا گۆڕاوان (Creating Variables)

بۆ دروستکرنا گۆڕاوەکێ، دڤێت جۆرێ وێ (Type) دیار بکەی و بەهایەکێ بدەیێ:

type variableName = value;
  • type: جۆرێ C# یە وەک int یان string.
  • variableName: ناڤێ گۆڕاوێ یە وەک x یان name.
  • هێمایا یەکسانیێ = بۆ دانانا بەهای (Assign value) بۆ گۆڕاوێ دهێتە بکارئینان.

نموونە (١): چێکرنا گۆڕاوەکێ ب ناڤێ name ژ جۆرێ string و دانانا بەهایێ "Kurdistan":

string name = "Kurdistan";
Console.WriteLine(name);
Kurdistan
هشیار بە! دەمێ تە دڤێت بەهایێ گۆڕاوەکێ چاپ بکەی، ناڤێ گۆڕاوێ بێی " " د ناڤ Console.WriteLine(name); دا بنڤیسە. ئەگەر تە نڤیسی "name" دێ پەیڤا name چاپ کەت، نەک Kurdistan!

دانانا بەهایان، گۆڕین، و خەلەتیێن گۆڕاوان

نموونە (٢): دروستکرن و دانانا بەهای:

int age = 25;
Console.WriteLine(age);

١. ناساندن (Declaration) و پێدانا بەهای (Initialization) جودا:

int age;        // declaration (ناساندن)
age = 25;       // initialization (پێدانا بەهای پاشتر)
Console.WriteLine(age);

٢. گۆڕینا بەهایێ هەیی (Overwrite): ئەگەر تە بەهایەکێ نوو دا گۆڕاوەکا هەیی، دێ بەهایێ کەڤن ژێبەت و یێ نوو وەرگریت:

int age = 25;
age = 20;       // age is now 20
Console.WriteLine(age);   // ئەنجام: 20
٣. تێبینیا خەلەتیێ (Compile-time Error): گۆڕاو دڤێت بەری بکارئینانێ بەهایەک پێ بهێتە دان، ئەگەر نە C# دێ خەلەتیێ دەت! 
int age;
int j = age; // compile-time error: Use of unassigned local variable 'age'

نەگۆڕ (Constants) و نموونێن دی

ئەگەر تە نەڤێت کەسەکێ دی (یان تو بخۆ) بەهایێ گۆڕاوەکێ بگۆڕیت، پەیڤا پاراستی یا const ل دەستپێکێ زێدە بکە. ئەڤە گۆڕاوێ دکەتە نەگۆڕ (Constant)، کو رامانا وێ نەگۆڕایە و بتنێ بۆ خواندنێ یە (Unchangeable and read-only):

const int age = 25;
age = 30; // error cannot be changed
تێبینیا گرنگ: تو نەشێی const ب ناسینی بێی کو هەر ل هەمان دەم بەهای بدەیێ! ئەگەر وە بکەی دێ خەلەتیا "A const field requires a value to be provided" دەرکەڤیت.

نموونێن سادە یێن جۆرێن دی:

int myAge = 15;
double myDoubleNum = 5.99D;
char myLetter = 'D';
bool myBool = true;
string myText = "Hello";
سلاید ١٦

نیشاندانا گۆڕاوان و پێکڤەگرێدان (Concatenation)

مێثۆدا WriteLine() گەلەک جاران بۆ نیشاندانا بەهایێ گۆڕاوان ل سەر شاشێ دهێتە بکارئینان.

پێکڤەگرێدان (Concatenation):

  • بۆ تێکەلکرنا دەقی و گۆڕاوێ، هێمایا + بکاردئینین:
string name = "Aram";
Console.WriteLine("Hello " + name);   // ئەنجام: Hello Aram
  • هەروەسا دشێی + بکاربینی بۆ زێدەکرنا گۆڕاوەکێ ل سەر گۆڕاوەکا دی:
string firstName = "Salar";
string lastName = "Raman";
string fullName = firstName + lastName;
Console.WriteLine(fullName);          // ئەنجام: SalarRaman
فێلا ئەزموونێ! تەماشەی firstName + lastName بکە: چونکی چ ڤالاتی (Space) د ناڤبەرا وان دا نەهاتیە دانان، ئەنجام دێ بێی ڤالاتی دەرکەڤیت: SalarRaman!

کۆمکرنا ژماران و فرە-گۆڕاو (Multiple Variables)

  • بۆ بەهایێن ژمارەیی (Numeric values): پیتا + وەک کریارا کۆمکرنا ماتماتیکی (Mathematical operator) کار دکەت:
int x = 10;
int y = 5;
Console.WriteLine(x + y); // ئەنجام: 15
  • ناساندنا پتر ژ گۆڕاوەکێ ژ هەمان جۆر (Same type): لیستەکا ب کۆما , جوداکری (Comma-separated list) بکاربینە:
int x = 5, y = 6, z = 50;
Console.WriteLine(x + y + z); // ئەنجام: 61

پەیڤێن پاراستی د C# دا (C# Keywords)

  • Keywords (پەیڤێن کلیل): پەیڤێن پاراستی نە (Reserved words) کو پێشوەختە بۆ کۆمپایلەرێ C# هاتینە پێناسەکرن.
  • ئەڤ پەیڤە نابیت وەک ناڤێ گۆڕاو یان ناسنامە (Identifiers) بهێنە بکارئینان.
  • رێکا جودا (Exception): ئەگەر تە خواست پەیڤەکا پاراستی وەک ناڤ بکاربینی، دڤێت ل دەستپێکا وێ هێمایا @ دانی (بۆ نموونە @class یان @int).

ناسنامە د C# دا (C# Identifiers)

  • هەمی گۆڕاوێن C# دڤێت ب ناڤێن تاکانە (Unique names) بهێنە ناسین. ئەڤ ناڤێن تاکانە دبێژنێ Identifiers.
  • دشێن ناڤێن کورت بن (وەک x و y) یان ناڤێن وەسفکەرتر بن (وەک age, sum, totalVolume).

یاسایێن گشتی یێن ناڤکرنێ (General Rules - زۆر گرنگن بۆ ئەزموونێ!):

  • ناڤ دشێت پیت (Letters)، ژمارە (Digits)، و ئەندەرسکۆر (_) تێدا بن.
  • ناڤ دڤێت ب پیتەکێ دەست پێ بکەت (Must begin with a letter).
  • باشترە ناڤ ب پیتەکا هویر دەست پێ بکەت (Should start with a lowercase letter) و نابیت ڤالاتی (Whitespace) تێدا بیت.
  • ناڤ هەستیارن بۆ پیتێن گر و هویر (Case sensitive): بۆ نموونە myVar و myvar دوو گۆڕاوێن جودا نە.
  • پەیڤێن پاراستی (وەک int یان double) نابیت وەک ناڤ بهێنە بکارئینان.

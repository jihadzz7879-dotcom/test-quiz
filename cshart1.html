What is C#

شڕۆڤە ب بادینی (ژ سفرێ):

  • خواندنا ناڤی: پیت و هێمایا C# وەک "C-Sharp or C-Hash" (سی شارپ یان سی هاش) دهێتە خواندن.
  • جۆر و چێکەر: زمانەکێ پرۆگرامسازیێ یێ Object-Oriented (OOP) یە، ژ لایێ کۆمپانیا Microsoft ڤە هاتیە چێکرن و ل سەر پلاتفۆرما .NET Framework کار دکەت.
  • ڕەگ و نێزیکاتی: ڕەگێ وی ژ خێزانا C دهێت، و زمان گەلەک نێزیکی زمانێن بەرنیاس یێن وەک C++ و Java یە.
  • سالا دەرکەفتنێ: ڤێرژنێ ئێکێ یێ C# ل سالا 2002 هاتیە بەڵاڤکرن.
💡 تێبینییا زێڕین بۆ تاقیکرنا وەرەقی:

ئەڤە بەربەڵاڤترین پرسیارا تێستێ یە! ٤ خالێن وێ وەک ئاڤێ ژبەر بکە:
• Pronounced: C-Sharp or C-Hash
• Created by: Microsoft | Runs on: .NET Framework
• Roots: C family | Close to: C++ and Java
• First version released: 2002

بۆچی زمانێ C# دهێتە بکارئینان؟ (مفایێن وی)

Why Use C# ?

شڕۆڤە ب بادینی — ٥ خالێن سەرەکی بۆچی C# دهێتە بکارئینان:

  1. ئێک ژ بەربەڵاڤترین زمانێن پرۆگرامسازیێ یە ل جیهانێ (one of the most popular programming language in the world).
  2. فێربوونا وی گەلەک ب ساناهی یە و بکارئینانا وی سادەیە (easy to learn and simple to use).
  3. پشتیڤانیەکا مەزن یا جڤاکی هەیە (huge community support).
  4. زمانەکێ Object-Oriented یە، کو پێکهاتەیەکا ڕوون ددەتە بەرنامان و ڕێکێ ددەت کۆد دووبارە بهێتە بکارئینان (code to be reused)، ئەڤە ژی تێچوویا گەشەپێدانێ کێم دکەت (lowering development costs).
  5. ژبەر کو نێزیکی C, C++ و Java یە، بۆ پرۆگرامسازان ساناهی یە ژ وان زمانان بهێنە سەر C# یان بەروڤاژی (easy to switch to C# or vice versa).

ئاگەهدارێ خالێ ٤ بە! ئەگەر پرسیار کر: "Why does C# lower development costs?" بەرسڤ: ژبەر کو زمانەکێ object-oriented یە کو پێکهاتەیەکا زەلال ددەت و ڕێکێ ددەت کۆد دووبارە بهێتە بکارئینان (reused).

شڕۆڤە ب بادینی — هێلکارییا کۆدێ سەرەکی د سلایدێ ٦ دا:

ل سلایدێ ٦ دا، پێکهاتەیا هەر بەرنامەیەکێ C# ب ڤی شێوەی ب خالێن سەرەکی هاتیە نیشاندان:

C# General Syntax DiagramSlide 6
using System;                // Import libraries (ئینانا کتێبخانان)

namespace test               // NameSpace: test (ناڤێ بۆشاییا ناڤی)
{
    class Program            // className: Program (ناڤێ کلاسێ)
    {
        static void Main(string[] args)  // Main Method (میتۆدێ سەرەکی)
        {
            // C# statements... (فەرمانێن C#)
        }
    }
}                            // End of the NameSpace (دوماهییا NameSpace)
💡 تێبینییا زێڕین بۆ تاقیکرنا وەرەقی:

د تاقیکرنێ دا ئەڤ هەیکەلە ژبەر بکە وەک ناڤێ خۆ! ئاگەهدار بە:
١) using System; ب S مەزن و ب ; بدوماهی دهێت.
٢) ل دوماهییا namespace test، class Program و Main(string[] args) چ ; ناهێتە دانان!
٣) Main پیتا M مەزنە، و string پیتا s بچووکە.
٤) ٣ کەڤانێن ڤەبوونێ { دڤێت ل بەرامبەر ٣ کەڤانێن گرتنێ } بن.

  • B) Main Method

  • D) C# statements

شڕۆڤەیا هەر بەشەکێ پێکهاتەیا C#

C# General Syntax — Detailed Explanation

شڕۆڤە ب بادینی — کارێ هەر ٥ پشکێن سەرەکی:

  1. using System: ڕامانا وێ ئەوە ئەم دکارین وان کلاسان بکاربینین یێن د ناڤ بۆشاییا ناڤێ System دا هەین.
  2. namespace: بۆ ڕێکخستنا کۆدی دهێتە بکارئینان و هەلگرێ (container) کلاسان و namespace یێن دی یە (container for classes and other namespaces).
  3. کەڤانێن پێچای {}: نیشانا دەستپێک و دوماهییا پارچە کۆدەکی (beginning and end of a block of code) ددەن.
  4. class: هەلگرێ داتا و میتۆدانە (container for data and methods) کو کارێن بەرنامەی دئیننە پێش. هەر ڕێزەکا کۆدی یا د C# دا کار دکەت، دڤێت د ناڤ class دا بیت! (د نموونێ دا ناڤێ وێ Program یە).
  5. میتۆدێ Main: تشتەکێ هەردەمی یە د بەرنامێ C# دا؛ هەر کۆدەکێ د ناڤ کەڤانێن وی {} دا بیت دێ هێتە جێبەجێکرن (executed).
💡 تێبینییا موهیم بۆ تاقیکرنا وەرەقی:

ئاگەهدارێ ڤێ جیاوازیا پێناسەیان بە:
• namespace = container for classes and other namespaces
• class = container for data and methods
• Main = Any code inside its curly brackets {} will be executed.

پرسیارا ١هەلبژارتن (MCQ)

  • A) namespace
  • B) class
  • C) using System
  • D) curly braces
بەرسڤا دروست: B class هەلگرێ داتا و میتۆدانە.
پرسیارا ٢پڕکرنا بۆشاییان
کەڤانێن {} نیشانا .................... و .................... یا پارچە کۆدەکی ددەن.
بەرسڤ: beginning (دەستپێک) و end (دوماهی).
پرسیارا ٣ڕاست و خەلەت
هەر ڕێزەکا کۆدی یا د C# دا جێبەجێ دبیت دڤێت د ناڤ class دا بیت.
بەرسڤ: True (ڕاستە) د سلایدێ ٧ دا هاتیە: Every line of code that runs in C# must be inside a class.
پرسیارا ٤پرسیارا کورت
کارێ namespace د C# دا چییە؟
بەرسڤ: بۆ ڕێکخستنا کۆدی دهێتە بکارئینان و هەلگرێ کلاسان و namespace یێن دی یە (container for classes and other namespaces).
پرسیارا ٥پڕکرنا بۆشاییان
هەر کۆدەکێ د ناڤ کەڤانێن میتۆدێ .................... دا بیت دێ هێتە جێبەجێکرن (executed).
بەرسڤ: میتۆدێ Main.
پرسیارا ٦پرسیارا کورت
بۆچی ل دەستپێکا کۆدی using System; دنڤێسین؟
بەرسڤ: دا بشێین وان کلاسان بکاربینین یێن د ناڤ System namespace دا هەین (وەک Console).

تێبینیێن گشتی (General Notes)

General Notes

شڕۆڤە ب بادینی — ٥ خالێن بنەڕەتی یێن زمانێ C#:

  1. Case Sensitive: زمانێ C# هەستیارە بەرامبەر پیتێن مەزن و بچووک؛ a جیاوازە ژ A.
  2. خال-فاریزە (; Semicolon): هەمی statements و expressions دڤێت ب خال-فاریزە ; بدوماهی بهێن.
  3. دەستپێکا بەرنامەی: جێبەجێکرنا بەرنامەی (program execution) ل میتۆدێ Main دەست پێ دکەت.
  4. جیاوازی دگەل Java: ل بەروڤاژی Java، ناڤێ فایلی د C# دا دکاریت جیاواز بیت ژ ناڤێ کلاسا د ناڤ دا.
  5. فەرمانا Console.ReadKey(): دکاریت ل دوماهیێ بهێتە زێدەکرن؛ بەرنامەی دئێخیتە هێڤیا لێدانا دوگمەیەکێ (key press) و ناهێلیت پەنجەرا کۆنسۆلی ب زوویی کار بکەت و خۆ بگرت دەمێ ژ Visual Studio .NET دهێتە ڤەکرن.
💡 تێبینییا موهیم بۆ تاقیکرنا وەرەقی:

ئەڤ سلایدە گەلەک بۆ پرسیارێن True/False و Short Answer دهێت! پەیڤا Unlike Java (ل بەروڤاژی جاڤا) و کارێ Console.ReadKey() باش ژبەر بکە.

جیاوازیا WriteLine و Write

WriteLine or Write in C#

شڕۆڤە ب بادینی:

  • بەربەڵاڤترین ڕێک بۆ چاپکرنێ WriteLine() یە، بەلێ دکاری Write() ژی بکاربینی.
  • جیاوازی: WriteLine() هەر جارێ دەرئەنجامی ل سەر ڕێزەکا نوو چاپ دکەت (دەقێ خۆ چاپ دکەت پاشی دچیتە هێلا خوارێ)، بەلێ Write() ل سەر هەمان ڕێزێ دمینیت و چاپ دکەت.
WriteLine vs Write ExampleSlide 10
Console.WriteLine("Hello World!");
Console.WriteLine("I will print on a new line.");
Console.Write("Hello World! ");
Console.Write("I will print on the same line.");
دەرئەنجام (Result): Hello World!
I will print on a new line.
Hello World! I will print on the same line.
💡 فەخێ تاقیکرنا وەرەقی — هشیار بە!

١) ئەو هێلا نوو یا WriteLine() ددەت ل پشتی چاپکرنا دەقێ وێ یە نەک ل پێشیێ! لەوما ئەگەر Write("A") ل پێشیێ بیت و WriteLine("B") ل دویڤ دا بیت، هەردووک ل ڕێزەکێ نە (AB) و پاشی تشتێ سیێ دچیتە ڕێزا نوو!
٢) هشیاری ڤالاهیا ناڤ "Hello World! " بە.

کۆمێنت د زمانێ C# دا

C# Comments

شڕۆڤە ب بادینی — کۆمێنت چییە و جۆرێن وێ چ نە؟

  • مەرەما کۆمێنتان: بۆ شڕۆڤەکرنا کۆدێ C# و خواندەڤانکرنا وی (explain C# code and make it more readable)، هەروەسا بۆ ڕاگرتنا جێبەجێکرنێ دەمێ تاقیکرنا کۆدێ جێگر (prevent execution when testing alternative code).
  • Single-line comments (ئێک-ڕێزی): ب دوو خەتێن خوار // دەست پێ دکەن.
  • Multi-line comments (فرە-ڕێزی): ب /* دەست پێ دکەن و ب */ بدوماهی دهێن.
Comments ExamplesSlide 11
// This is a comment
Console.WriteLine("Hello World!"); // This is another comment

/* The code below will print the words Hello World to the 
screen, and it is amazing */
Console.WriteLine("Hello World!");

C# Variables — Declaration, Initialization, Overwrite & Error

شڕۆڤە ب بادینی — هەر ٤ حالەتێن سلایدێ ١٤:

  1. نموونا ٢: int age = 25; و چاپکرنا وی (25).
  2. دوو قۆناغ (Declare & Assign Later): ل سەرێ ڕێزەکا ئێکێ ڕادگەهینی (int age; ← declaration) و ل ڕێزا دووێ بهای ددەیێ (age = 25; ← initialization).
  3. گوهۆڕینا بهای (Overwrite): ئەگەر بهایەکێ نوو بدەیە گۆڕاوەکێ هەی (age = 20;)، دێ بهایێ بەرێ (25) ژێبەت و یێ نوو (20) دێ مینیت.
  4. خەلەتییا گۆڕاوێ بێ بها: گۆڕاو دڤێت بهایەکی وەربگریت بەری بکارئینانا وی؛ ئەگەر نە، C# دێ خەلەتیێ دەت!
Slide 14 Code CasesC# Code
int age = 25;
Console.WriteLine(age);       // Output: 25

int age;                      // declaration (ڕاگەهاندن)
age = 25;                     // initialization (بهاپێدان)
Console.WriteLine(age);       // Output: 25

int age = 25;
age = 20;                     // age is now 20 (گوهۆڕین)
Console.WriteLine(age);       // Output: 20
⛔ خەلەتییا وەختێ کۆمپایلکرنێ (Compile-time error):
int age;
int j = age; // compile-time error: Use of unassigned local variable 'age'
💡 تێبینییا موهیم بۆ تاقیکرنا وەرەقی:

١) دەمێ بهایێ گۆڕاوی دگوهۆڕی (age = 20;)، پەیڤا int ل پێشیا وی نەنڤێسە!
٢) ناڤێ هەردوو تێگەهان ژبەر بکە: int age; = declaration ، و age = 25; = initialization.

پرسیارا ٣پڕکرنا بۆشاییان

C# Variables — Constants & Other Types

شڕۆڤە ب بادینی:

  • پەیڤا const: تۆ دکاری پەیڤا const زێدە بکەی ئەگەر تە نەڤێت کەسێن دی (یان تۆ ب خۆ) بهایێن هەی بگوهۆڕن. ئەڤە گۆڕاوی وەک "constant" ڕادگەهینیت کو ڕامانا نەگوهۆڕ و ب تنێ بۆ خواندنێ (unchangeable and read-only) ددەت.
  • یاسایا گرنگ: تۆ نەشێی گۆڕاوەکێ نەگۆڕ (const) بێی بهاپێدانێ ڕابگەهینی! ئەگەر بکەی، دێ خەلەتی دەرکەڤیت: "A const field requires a value to be provided".
  • هەروەسا سلاید نموونێن سادە یێن هەمی ٥ جۆران پێکڤە نیشا ددەت.

How to Display Variables — Concatenation

شڕۆڤە ب بادینی:

  • میتۆدێ WriteLine() گەلەک جاران بۆ نیشاندانا بهایێ گۆڕاوان ل سەر پەنجەرا کۆنسۆلی دهێتە بکارئینان.
  • پێکڤەلکاندن (Concatenation): بۆ تێکەلکرنا دەقەکی و گۆڕاوەکی، نیشانا + بکاربینە: "Hello " + name.
  • هەروەسا دکاری نیشانا + بکاربینی بۆ لکاندنا گۆڕاوەکێ دەقی ب گۆڕاوەکێ دی یێ دەقی ڤە: firstName + lastName.
Concatenation ExamplesSlide 16
string name = "Aram";
Console.WriteLine("Hello " + name);

string firstName = "Salar";
string lastName = "Raman";
string fullName = firstName + lastName;
Console.WriteLine(fullName);
دەرئەنجام (Output): Hello Aram
SalarRaman

ل سلایدێ ١٦ دا، firstName + lastName دەرئەنجامێ وێ SalarRaman بێی ڤالاهی یە، چونکی نە د ناڤ "Salar" دا و نە د ناڤ "Raman" دا ڤالاهی نینە! ل سەر وەرەقێ پێکڤە نووسیای بنڤێسە ئەگەر " " د ناڤبەرا وان دا نەبیت!

نیشانا + ل گەل ژماران و ڕاگەهاندنا گەلەک گۆڕاوان

How to Display Variables — Numeric + & Comma-Separated List

شڕۆڤە ب بادینی:

  • بۆ بهایێن ژمارەیی (Numeric values): هێمایێ + وەک کارکەرەکێ ماتماتیکی (mathematical operator) کار دکەت و ژماران کۆم دکەت (بۆ نموونە ل گەل int).
  • ڕاگەهاندنا پتر ژ ئێک گۆڕاوی ژ هەمان جۆری: بۆ چێکرنا گەلەک گۆڕاوان ژ هەمان جۆری (same type)، لیستا ب فاریزێ جوداکری (comma-separated list) بکاربینە!
Numeric Addition & Multiple VariablesSlide 17
int x = 10;
int y = 5;
Console.WriteLine(x + y); // Print the value of x + y  => 15

int x = 5, y = 6, z = 50;
Console.WriteLine(x + y + z); // => 61
دەرئەنجام (Output): 15
61
💡 تێبینییا موهیم بۆ تاقیکرنا وەرەقی:

ئاگەهدار بە ل ڕاگەهاندنا گەلەک گۆڕاوان: int x = 5, y = 6, z = 50; — پەیڤا int تنێ ئێک جار ل دەستپێکێ دهێت، فاریزە (,) د ناڤبەرا وان دا، و خال-فاریزە (;) ل دوماهیێ!

بەرسڤ: 61

  • A) Semicolon (;)
  • B) Comma (,)
  • C) Dot (.)
  • D) Hash (#)

شڕۆڤە ب بادینی:

  • Keywords: پەیڤێن حەجزکرینە کو پێشوەختە بۆ کۆمپایلەرێ C# هاتینە پێناسەکرن (reserved words predefined to the C# compiler).
  • ئەڤ پەیڤە چێنابیت وەک ناڤێ گۆڕاوان (identifiers) بهێنە بکارئینان!
  • ڕێکا ئاوارتە: ئەگەر تە گەلەک بڤێت ڤان پەیڤان وەک identifier بکاربینی، دکاری هێمایێ @ ل پێشیا وان دانێی (prefix them with the @ character)، وەک @class یان @int.

ئەگەر پرسیار کر: "Can we use keywords as variable names?" ← بێژە: ب شێوەیێ گشتی نەخێر (No)، بەلێ ئەگەر هێمایێ @ دانینە پێشیا وێ (وەک @for یان @class) دکارین بکاربینین!

ناڤێن گۆڕاوان و یاسایێن گشتی

C# Identifiers

شڕۆڤە ب بادینی — Identifiers و ٥ یاسایێن وان:

  • هەمی گۆڕاوێن C# دڤێت ب ناڤێن تایبەت (unique names) بهێنە ناسین؛ ئەڤ ناڤانە دبێژنێ identifiers.
  • دکارن ناڤێن کورت بن (وەک x و y) یان ناڤێن وەسفکەر بن (وەک age, sum, totalVolume).

یاسایێن گشتی (General Rules) ل دویڤ سلایدێ ١٩:

  1. ناڤ دکارن پیتان (letters)، ژماران (digits) و هێلا ژێری (_ underscore) ب خۆڤە بگرن.
  2. ناڤ پێدڤیە ب پیتەکێ دەست پێ بکەن (Names must begin with a letter).
  3. ناڤ پێدڤیە ب پیتەکا بچووک دەست پێ بکەن و چێنابیت ڤالاهی (whitespace) تێدا هەبیت.
  4. ناڤ هەستیارن بەرامبەر پیتێن مەزن و بچووک (case sensitive)؛ "myVar" و "myvar" دوو گۆڕاوێن جودانە.
  5. پەیڤێن حەجزکری (وەک int یان double) چێنابیت وەک ناڤ بهێنە بکارئینان.
💡 پرسیارا هەرە مسۆگەر یا وەرەقێ:

ب پشتڕاستی ڤە دێ پرسیارەکا Valid vs Invalid Identifiers هێت!
✅ دروست: age, sum, totalVolume, num_1
❌ خەلەت: 1num (ب ژمارە دەستپێکریە)، my num (ڤالاهی تێدا هەیە)، my-num (هێمایێ - تێدا هەیە)، double (پەیڤا حەجزکری یە).

پرسیارا ١Valid / Invalid

بەرسڤ: a) Valid  |  b) Invalid (ب ژمارە دەستپێکریە)  |  c) Invalid (ڤالاهی تێدا هەیە)  |  d) Valid  |  e) Invalid (keyword یە).

بەرسڤ: ١) Contain letters, digits, underscore (_). ٢) Must begin with a letter. ٣) Start with lowercase & no whitespace. ٤) Case sensitive. ٥) Reserved words cannot be used.

  • B) Underscore (_)

  • D) Star (*)
بەرسڤا دروست: B هێمایێ Underscore (_).

بەرسڤ: identifiers.

بەرسڤ: 10 (7 + 3 = 10، چونکی دوو گۆڕاوێن جودانە).

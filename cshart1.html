🔹 سلاید ٣: C# چیە؟ (What is C#)

  • خاندنا ناڤی: C# دهێتە خواندن "C-Sharp or C-Hash".
  • پێناسە: زمانەکێ پرۆگرامسازیێ یێ Object-Oriented (OOP)ە کو ژ لایێ کۆمپانیا Microsoft ڤە هاتیە چێکرن و ل سەر .NET Framework کاردکەت.
  • رەگ و ریشال: ژ خێزانا زمانێ C یە، و گەلەک نێزیکی زمانێن بەرنیاسێن وەک C++ و Java یە.

🔹 سلاید ٥: بۆچی C# بکار بینین؟ (Why Use C# ?)

  • ئێک ژ بەربەلاڤترین زمانێن پرۆگرامسازیێ یە ل جیهانێ.
  • فێربوونا وی یا ب ساناهی یە (Easy to learn) و بکارئینانا وی سادەیە (Simple to use).
  • کۆمەڵگەهەکا مەزن یا پشتگیریێ هەیە (Huge community support).
  • زمانەکێ Object-Orientedە: پێکهاتەکێ رۆهن (Clear structure) ددەتە پرۆگرامان و رێکێ ددەت کۆد دووبارە بهێتە بکارئینان (Reused)، ئەڤە ژی خەرجیێن دروستکرنێ کێم دکەت (Lowering development costs).
  • ژبەر کو نێزیکی C, C++, Java یە، بۆ پرۆگرامسازان ب ساناهی یە ژ وان زمانان بهێنە سەر C# یان بەروڤاژی.
📝 پسیارێن سلاید ٥ (٥ پسیار):
١. چەوا C# خەرجیێن دروستکرنا پرۆگرامان (Development costs) کێم دکەت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
چونکی Object-Orientedە و رێکێ ددەت کۆد دووبارە بهێتە بکارئینان (Allows code to be reused).

چونکی زمانێ C# گەلەک نێزیکی C, C++, و Java یە.

١) Easy to learn and simple to use. ٢) Huge community support (یان پۆپیولەرە / OOPە).

🔹 سلاید ٧: شەرحا پێکهاتێ گشتی (Syntax Details)

  • using System: مانا وێ ئەوە ئەم دشێین کلاسێن ژ ناڤ System namespace بکار بینین.
  • namespace: بۆ رێکخستنا کۆدی دهێتە بکارئینان، و قووتیکەکە (Container) بۆ هەڵگرتنا کلاسان و namespaceێن دی.
  • کڤانێن {}: دەستپێک و دوماهیا بلۆکەکێ کۆدی دیار دکەن.
  • class: قووتیکەکە بۆ داتا و مێسۆدان (Data & Methods) کو کار ددەتە پرۆگرامی. هەر رێزەکا کۆدی یا کاربکەت د C# دا دڤێت د ناڤ کلاسی دا بیت.
  • Main method: هەردەم د پرۆگرامێ C# دا هەیە؛ هەر کۆدەکێ د ناڤ {} یێن وێ دا بیت دێ هێتە جێبەجێکرن (Executed).

🔹 سلاید ٩: تێبینیێن گشتی (General Notes)

  • Case sensitive: زمانێ C# هەستیارە بۆ پیتێن مەزن و بچویک؛ a جودایە ژ A.
  • Semicolon (;): هەمی ڕستە و دەربڕین (Statements & expressions) دڤێت ب خاڵ-کۆما (;) بدوماهیک بهێن.
  • Main method: جێبەجێکرنا پرۆگرامی ژ Main method دەستپێدکەت.
  • جوداهیا ژ Java: بەروڤاژی Java، ناڤێ فایلێ پرۆگرامی دشێت جودا بیت ژ ناڤێ کلاسی.
  • Console.ReadKey(): ل دوماهیێ دهێتە زێدەکرن دا پرۆگرام چاڤەڕێی لێدانا کلیتەکێ بکەت و شاشە ب لەز نەهێتە گرتن دەمێ ژ Visual Studio .NET کار پێ دکەی.
📝 پسیارێن سلاید ٩ (٥ پسیار):
١. رامانا C# is Case sensitive چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
پیتێن مەزن (Capital) جودانە ژ پیتێن بچویک (Small)، بۆ نموونە a جودایە ژ A.
٢. هەمی ڕستەیێن C# دڤێت ب چ هێمایەکێ بدوماهیک بهێن؟
👇 تبلێ لێبدە بۆ بەرسڤێ
ب Semicolon (;).

ل Main method.

🔹 سلاید ١٠: جوداهیا WriteLine و Write

  • بەربەلاڤترین رێک بۆ چاپکرنێ WriteLine()ە، بەلێ دشێی Write() ژی بکار بینی.
  • جوداهی: WriteLine() هەر جار ل سەر رێزەکا نوی (New line) چاپ دکەت، بەلێ Write() ل سەر هەمان رێزێ (Same line) چاپ دکەت.
Console.WriteLine("Hello World!");
Console.WriteLine("I will print on a new line.");
Console.Write("Hello World! ");
Console.Write("I will print on the same line.");
ئەنجامێ ئەڤی کۆدی ٣ رێزن (ب وردی سەحکێ JEHAD ZEBARE!):
رێزا ١: Hello World!
رێزا ٢: I will print on a new line.
رێزا ٣: Hello World! I will print on the same line.
📝 پسیارێن سلاید ١٠ (٦ پسیار):
١. جوداهیا سەرەکی د ناڤبەرا WriteLine() و Write() دا چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
WriteLine() ل سەر رێزەکا نوی چاپ دکەت (پشتی چاپێ دچیتە رێزا خوارێ)، بەلێ Write() ل سەر هەمان رێزێ دمینیت.
٢. ئەنجامێ Console.Write("JEHAD "); Console.Write("ZEBARE"); چەوا دێ دەرکەڤیت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
ل سەر ئێک رێز: JEHAD ZEBARE
٣. ئەنجامێ ئەڤی کۆدی چەند رێزە و چیە؟ Console.WriteLine("1"); Console.Write("2"); Console.WriteLine("3");
👇 تبلێ لێبدە بۆ بەرسڤێ
دوو رێز:
رێزا ١: 1
رێزا ٢: 23
٤. د نموونەیا سلاید ١٠ دا، بۆچی "Hello World! " و "I will print on the same line." ل سەر ئێک رێز چاپ بوون؟
👇 تبلێ لێبدە بۆ بەرسڤێ
چونکی فرمانا ئێکێ یا رێزا سێیێ Console.Write(...) بوو و نەچوو رێزەکا نوی.
٥. کیژ مێسۆد پتر بەربەلاڤە بۆ نیشاندانا ئەنجامی د C# دا؟
👇 تبلێ لێبدە بۆ بەرسڤێ
WriteLine()
٦. ئەگەر Console.Write("Akre"); Console.WriteLine("IT"); بهێتە جێبەجێکرن، ئەنجام چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
AkreIT (ل سەر ئێک رێز و بێ سپەیس).

🔹 سلاید ١١: کۆمێنت د C# دا (C# Comments)

  • کۆمێنت بۆ شەرحکرنا کۆدی دا جوانتر بهێتە خواندن، هەروەسا بۆ راوەستاندنا جێبەجێکرنا کۆدی دەمێ تاقیکرنا کۆدەکێ دی دهێتە بکارئینان.
  • Single-line comment: ب دوو هێلێن خوار // دەستپێدکەت.
  • Multi-line comment: ب /* دەستپێدکەت و ب */ بدوماهیک دهێت.
// Single-line comment for JEHAD ZEBARE
Console.WriteLine("Hello World!"); // Another comment

/* Multi-line comment:
   prints Hello World to the screen */
Console.WriteLine("Hello World!");
📝 پسیارێن سلاید ١١ (٥ پسیار):
١. دوو مفا یان ئارمانجێن کۆمێنتان د C# دا بنڤیسە.
👇 تبلێ لێبدە بۆ بەرسڤێ
١) شەرحکرنا کۆدی و ب ساناهیکرنا خواندنا وی. ٢) راوەستاندنا جێبەجێکرنا کۆدی دەمێ تاقیکرنا کۆدەکێ جێگر.
٢. کۆمێنتا ئێک رێزی (Single-line) ب چ هێمایەکێ دەستپێدکەت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
// (دوو forward slashes).
٣. کۆمێنتا فرە-رێزی (Multi-line) ب چ دەستپێدکەت و ب چ بدوماهیک دهێت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
ب /* دەستپێدکەت و ب */ بدوماهیک دهێت.
٤. ئەنجامێ ئەڤی کۆدی چیە؟
// Console.WriteLine("Test");
Console.WriteLine("JEHAD ZEBARE");
👇 تبلێ لێبدە بۆ بەرسڤێ
بتنێ JEHAD ZEBARE دێ چاپ بیت.
٥. ئەگەر تو /* بنڤیسی لێ ژبیر بکەی */ ل دوماهیێ بنڤیسی، چ چێدبیت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
کۆدێ پشتی وێ هەمی وەک کۆمێنت دێ هێتە هژمارتن و خەلەتی (Error) دێ دروست بیت.

🔹 سلاید ١٢: گۆڕاو و جۆرێن داتایان (C# Variables)

Variables: قووتیکانن بۆ هەڵگرتنا بەهایێن داتایان (Containers for storing data values).
جۆرێن سەرەکی د سلایدی دا:
  • int: ژمارێن تمام (بێ پۆینت)، وەک 123 یان -123.
  • double: ژمارێن دەهی (ب پۆینت)، وەک 19.99 یان -19.99.
  • char: ئێک پیت یان هێما د ناڤ تاک کۆتەیشن دا، وەک 'a' یان 'B'.
  • string: نڤیسین و دەق د ناڤ دەبل کۆتەیشن دا، وەک "Hello World" یان "JEHAD ZEBARE".
  • bool: دوو بەها هەنە: true یان false.
📝 پسیارێن سلاید ١٢ (٦ پسیار):
١. پێناسەیا Variables بکە د C# دا.
👇 تبلێ لێبدە بۆ بەرسڤێ
قووتیکانن بۆ هەڵگرتنا بەهایێن داتایان (Containers for storing data values).
٢. جوداهی د ناڤبەرا char و string دا چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
char بتنێ ئێک پیت هەڵدگریت د ناڤ تاک کۆتەیشن ' ' دا، بەلێ string دەق هەڵدگریت د ناڤ دەبل کۆتەیشن " " دا.
٣. بۆ هەر ئێک ژ (-123, 19.99, 'J', "JEHAD", false) کیژ جۆر دهێتە بکارئینان؟
👇 تبلێ لێبدە بۆ بەرسڤێ
-123 → int | 19.99 → double | 'J' → char | "JEHAD" → string | false → bool.
٤. ئەرێ int دشێت ژمارەکا ب پۆینت وەک 5.5 هەڵبگریت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
نەخێر، int بتنێ ژمارێن تمام (بێ پۆینت) هەڵدگریت.
٥. جۆرێ bool چەند حالەت یان بەهایان هەڵدگریت؟ کیژن؟
👇 تبلێ لێبدە بۆ بەرسڤێ
دوو حالەتان: true یان false.
٦. بۆچی char c = "A"; خەلەتە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
چونکی بەهایێ char دڤێت د ناڤ تاک کۆتەیشن 'A' دا بیت نە دەبل کۆتەیشن.

🔹 سلاید ١٣: چەوا گۆڕاوی دروست بکەین؟ (Variables Syntax)

Syntax: type variableName = value;
  • type: جۆرێ گۆڕاوی (وەک int یان string).
  • variableName: ناڤێ گۆڕاوی (وەک x یان name).
  • =: بۆ دانانا بەهای بۆ گۆڕاوی دهێتە بکارئینان.
string name = "Kurdistan";
Console.WriteLine(name);   // ئەنجام: Kurdistan
📝 پسیارێن سلاید ١٣ (٥ پسیار):
١. یاسایا گشتی (Syntax) یا دروستکرنا گۆڕاوی د C# دا بنڤیسە.
👇 تبلێ لێبدە بۆ بەرسڤێ
type variableName = value;
٢. کارێ نیشانا = د ناساندنا گۆڕاوی دا چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
بۆ دانانا بەهای بۆ گۆڕاوی (Assign values to the variable).
٣. گۆڕاوەکێ ب ناڤێ student ژ جۆرێ string چێبکە و بەهایێ "JEHAD ZEBARE" بدەیێ و چاپ بکە.
👇 تبلێ لێبدە بۆ بەرسڤێ
string student = "JEHAD ZEBARE";
Console.WriteLine(student);
٤. جوداهی د ناڤبەرا Console.WriteLine(name); و Console.WriteLine("name"); چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
یا ئێکێ بەهایێ د ناڤ گۆڕاوێ name دا چاپ دکەت، یا دووێ راستەوخۆ پەیڤا name چاپ دکەت.
٥. ئەنجامێ string name = "Kurdistan"; Console.WriteLine(name); چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
Kurdistan

🔹 سلاید ١٤: ناساندن، گۆڕین و خەلەتیا بەهایێ نەدانای

int age;          // declaration (ناساندن)
age = 25;         // initialization (دانانا بەهای)
Console.WriteLine(age); // 25

int age2 = 25;
age2 = 20;        // overwrite (بەهایێ کەڤن دسڕیتەڤە، نوکە 20ە)
Console.WriteLine(age2); // 20

int x;
int j = x;        // Error! Use of unassigned local variable 'x'
📝 پسیارێن سلاید ١٤ (٦ پسیار):
١. جوداهی د ناڤبەرا int age; و age = 25; چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
int age; بریتیە ژ ناساندن (Declaration)، و age = 25; بریتیە ژ بەها دانان (Initialization).
٢. ئەنجامێ ئەڤی کۆدی چیە؟ int age = 25; age = 20; Console.WriteLine(age);
👇 تبلێ لێبدە بۆ بەرسڤێ
20 (بەهایێ ٢٥ هاتە گۆڕین بۆ ٢٠).
٣. بۆچی int age; int j = age; خەلەتیێ (Compile-time error) ددەت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
چونکی گۆڕاوێ age بەری بهێتە بکارئینان چ بەها نەهاتیە دانێ (Use of unassigned local variable 'age').
٤. ئەرێ د C# دا دشێین گۆڕاوەکی بناسینین و پاشی ل رێزا دی بەهای بدەینێ؟
👇 تبلێ لێبدە بۆ بەرسڤێ
بەلێ (True)، وەک int age; age = 25;.
٥. دەما بەهایەکێ نوی ددەینە گۆڕاوەکێ بەرێ هەی، چ ب سەرێ بەهایێ کەڤن دهێت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
بەهایێ نوی ل سەر یێ کەڤن دهێتە نڤیسین (Overwrite) و بەهایێ کەڤن نامینیت.
٦. ئەنجامێ int m = 10; m = 50; m = 99; Console.WriteLine(m); چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
99

🔹 سلاید ١٥: نەگۆڕەکان (Constants) و نموونێن جۆران

  • پەیڤا const گۆڕاوی دکەتە نەگۆڕ و بتنێ-خواندن (Unchangeable and read-only)؛ کەس نەشێت بگۆڕیت.
  • یاسایا گرنگ: نەشێی const بێ بەها بناسینی! دڤێت د هەمان رێز دا بەهای بدەیێ (ئەگەر نە خەلەتی: A const field requires a value to be provided).
const int age = 25;
// age = 30;  // Error! cannot be changed

int myAge = 15;
double myDoubleNum = 5.99D;
char myLetter = 'D';
bool myBool = true;
string myText = "Hello";
📝 پسیارێن سلاید ١٥ (٦ پسیار):
١. کارێ پەیڤا const چیە د C# دا؟
👇 تبلێ لێبدە بۆ بەرسڤێ
گۆڕاوی دکەتە نەگۆڕ (Constant)، ئانکو بەهایێ وێ ناهێتە گۆڕین و بتنێ بۆ خواندنێ یە (Unchangeable and read-only).
٢. ئەنجامێ ئەڤی کۆدی چیە؟ const int age = 25; age = 30;
👇 تبلێ لێبدە بۆ بەرسڤێ
خەلەتی (Error)، چونکی بەهایێ const ناهێتە گۆڕین.
٣. بۆچی const int x; x = 10; خەلەتە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
چونکی ناهێتە ناساندن بێ دانانا بەهای د هەمان رێز دا (A const field requires a value to be provided).
٤. د double myDoubleNum = 5.99D; دا، پیتا D چ نیشان ددەت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
دیاردکەت کو ژمارە ژ جۆرێ doubleە.
٥. گۆڕاوەکێ نەگۆڕ بۆ سالا 2025 بۆ JEHAD ZEBARE چێبکە.
👇 تبلێ لێبدە بۆ بەرسڤێ
const int year = 2025;
٦. ئەرێ راستە بێژین گۆڕاوێ const دشێت ب درێژاهیا پرۆگرامی دوو جاران بهێتە گۆڕین؟
👇 تبلێ لێبدە بۆ بەرسڤێ
False (خەلەتە، چ جاران ناهێتە گۆڕین).

🔹 سلاید ١٦: نیشاندانا گۆڕاوان (Concatenation)

فەنکشنا WriteLine() بۆ نیشاندانا بەهایێ گۆڕاوان دهێتە بکارئینان. ب هێمایا + ئەم دەقان و گۆڕاوێن دەقی ب ئێکڤە دگرێدەین (ئەڤێ کریارێ دبێژنێ Concatenation): 
string name = "Aram";
Console.WriteLine("Hello " + name);     // ئەنجام: Hello Aram

string firstName = "Salar";
string lastName = "Raman";
string fullName = firstName + lastName;
Console.WriteLine(fullName);            // ئەنجام: SalarRaman
📝 پسیارێن سلاید ١٦ (٥ پسیار):
١. ناڤێ کریارا لێکدانا دەق و گۆڕاوێن دەقی ب نیشانا + چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
Concatenation.
٢. ئەنجامێ string firstName = "Salar"; string lastName = "Raman"; Console.WriteLine(firstName + lastName); چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
SalarRaman (بێ سپەیس د ناڤبەرا وان دا).
٣. ئەنجامێ string name = "JEHAD ZEBARE"; Console.WriteLine("Hello " + name); چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
Hello JEHAD ZEBARE
٤. چەوا دێ سپەیسەکێ بێخیە ناڤبەرا firstName و lastName ل دەمێ لێکدانێ دا؟
👇 تبلێ لێبدە بۆ بەرسڤێ
string fullName = firstName + " " + lastName;
٥. کیژ هێما بۆ تێکەلکرنا دەق و گۆڕاوێ string دهێتە بکارئینان؟
👇 تبلێ لێبدە بۆ بەرسڤێ
نیشانا +.

🔹 سلاید ١٧: کارێ + دگەل ژماران، و چەند گۆڕاو پێکڤە

  • بۆ بەهایێن ژمارەیی (int, double)، نیشانا + وەک کردارەکا ماتماتیکی (کۆمکرن) کاردکەت.
  • بۆ ناساندنا پتر ژ گۆڕاوەکێ ژ هەمان جۆر، کۆما (,) دهێتە بکارئینان:
int x = 10;
int y = 5;
Console.WriteLine(x + y);           // ئەنجام: 15

int a = 5, b = 6, z = 50;
Console.WriteLine(a + b + z);       // ئەنجام: 61
📝 پسیارێن سلاید ١٧ (٥ پسیار):
١. دگەل ژمارەیان (int)، نیشانا + چەوا کاردکەت؟
👇 تبلێ لێبدە بۆ بەرسڤێ
وەک کردارەکا ماتماتیکی (Mathematical operator) کۆم دکەت.
٢. ئەنجامێ int x = 5, y = 6, z = 50; Console.WriteLine(x + y + z); چیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
61
٣. چ هێمایەکێ د ناڤبەرا گۆڕاوان دا ددانین دەمێ پتر ژ گۆڕاوەکێ ژ هەمان جۆر د ئێک رێز دا دناسینین؟
👇 تبلێ لێبدە بۆ بەرسڤێ
کۆما (,) — Comma-separated list.
٤. ئەنجامێ Console.WriteLine(10 + 5); دگەل Console.WriteLine("10" + "5"); چ جوداهی هەیە؟
👇 تبلێ لێبدە بۆ بەرسڤێ
یا ئێکێ 15 چاپ دکەت (کۆمکرن)، یا دووێ 105 چاپ دکەت (Concatenation).
٥. سێ گۆڕاوێن int ب ناڤێن n1=1, n2=2, n3=3 د ئێک رێز دا بنڤیسە.
👇 تبلێ لێبدە بۆ بەرسڤێ
int n1 = 1, n2 = 2, n3 = 3;

🔹 سلاید ١٨: پەیڤێن حەجزکری (C# Keywords)

  • Keywords: پەیڤێن حەجزکرینە (Reserved words) کو پێشوەخت بۆ کۆمپایلەرێ C# هاتینە دیارکرن.
  • نابیت وەک ناڤێ گۆڕاوی (Identifiers) بهێنە بکارئینان.
  • بەلێ ئەگەر بڤێت وەک ناڤ بکار بینی، دڤێت نیشانا @ بێخیە بەراهیا وێ (وەک @class).
  • نموونێن جدولێ سلاید ١٨: abstract, as, base, bool, break, byte, case, catch, char, checked, class, const, continue, decimal, default, delegate, do, double, else, enum, event, explicit, extern, false, finally, fixed, float, for.
📝 پسیارێن سلاید ١٨ (٥ پسیار):
١. پێناسەیا Keywords بکە د C# دا.
👇 تبلێ لێبدە بۆ بەرسڤێ
ئەو پەیڤێن حەجزکرینە (Reserved words) یێن پێشوەخت بۆ کۆمپایلەرێ C# هاتینە دیارکرن.
٢. چ هێمایەکێ ل بەراهیا Keywordێ ددانین ئەگەر مە بڤێت بکەینە ناڤێ گۆڕاوی (Identifier)؟
👇 تبلێ لێبدە بۆ بەرسڤێ
هێمایا @ (بۆ نموونە @class یان @int).
٣. ئەرێ int bool = 5; دروستە؟ بۆچی؟
👇 تبلێ لێبدە بۆ بەرسڤێ
نەخێر خەلەتە، چونکی bool Keywordە و نیشانا @ ل گەل نینە.
٤. پێنج نموونان ژ جدولێ Reserved Keywords یێ سلاید ١٨ بنڤیسە.
👇 تبلێ لێبدە بۆ بەرسڤێ
abstract, bool, break, class, const (یان هەر ٥ ژ جدولی).
٥. کیژ ژ ئەڤان خەلەتە: int @for = 1; یان int for = 1;؟
👇 تبلێ لێبدە بۆ بەرسڤێ
int for = 1; خەلەتە، چونکی for پەیڤەکا حەجزکریە.

🔹 سلاید ١٩: ناسکەر و یاسایێن ناڤدانانێ (C# Identifiers)

هەمی گۆڕاوێن C# دڤێت ناڤێن تایبەت (Unique names) هەبن، دبێژنێ Identifiers (وەک x, age, sum, totalVolume).
یاسایێن گشتی ل دویڤ سلاید ١٩:

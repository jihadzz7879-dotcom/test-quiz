بنەمایێن پرۆگرامسازیێ ب زمانێ #C

زانکۆیا ئاکرێ بۆ زانستێن کرداری (AUAS) - پەیمانگەها تەکنیکی یا ئاکرێ - بەشێ IT

شروڤەکرنا تەمام ب بادینی + پسیارێن هەر سلایدەکی + تاقیکرنا گشتی یا نەزەری (سەر وەرەقێ)

ئامۆژگاریێن زێڕین بۆ تاقیکرنا نەزەری (ل سەر وەرەقێ) رۆژا ئێکشەمبێ:

  • سیمی کۆڵۆن ; ژبیر نەکە: د وەرەقێ دا گەلەک قوتابی د نڤیسینا کۆدی دا ; ل دوماھیا ڕێزێ ژبیر دکەن، ئەڤە د تاقیکرنێ دا نمرەیان دئینیتە خوارێ.
  • پیتێن مەزن و بچووک (Case Sensitive): د #C دا Console.WriteLine و Main و System پیتا وان یا ئێکێ مەزنە، و int، string، class، namespace هەمی ب پیتێن بچووکن.
  • کۆتەیشنێن تاک و دوو لێڤ (' ' و " "): بۆ char تەنێ تاک کۆتەیشن 'A' و بۆ string دوو کۆتەیشن "Hello" دهێتە بکارئینان.
  • سەر و بنێن کۆدی { }: ل بیرت بیت هەر کڤانەکا تو ڤەدکەی دڤێت ل دوماهیێ بگری.

سلایدێ ٣: زمانێ #C چییە؟ (What is C#)

Slide 3

د ڤی سلایدی دا پێناسا زمانێ #C و دیرۆکا وی ب کورتی هاتیە:

  • چەوا دهێتە گوتن (Pronunciation): #C ب "C-Sharp" یان "C-Hash" دهێتە گوتن. (ل سەر وەرەقێ ئەڤ هەردوو ناڤە گرنگن چونکی سلایدی ب خۆ وەسا نڤیسییە!)
  • جۆرێ زمانی و کۆمپانی: زمانەکێ پرۆگرامسازیێ یە یێ Object-Oriented (ئاراستەکری ب ئۆبجێکتان) کو ژ لایێ کۆمپانیا Microsoft (مایکرۆسۆفت) ڤە هاتیە چێکرن و ل سەر .NET Framework کار دکەت.
  • ڕەگ و ڕیشێن وی: #C ژ خێزانا زمانێ C هاتیە، و گەلەک نێزیکی زمانێن بەرنیاسێن دی یە وەک ++C و Java.
  • ساڵا دەرچوونێ: ئێکەم ڤێرژنا #C د ساڵا 2002 دا دەرچوو.

پسیارێن سلایدێ ٣ (٦ پسیار):

١. پێناسا زمانێ #C بکە (What is C#?) ب گۆرەی سلایدی.
بەرسڤ: #C زمانەکێ پرۆگرامسازیێ یێ Object-Oriented یە ژ لایێ Microsoft ڤە هاتیە چێکرن، ل سەر .NET Framework کار دکەت، ڕەگێ وی ژ خێزانا C یە و نێزیکی ++C و Java یە، ئێکەم ڤێرژنا وی د ساڵا 2002 دا دەرچوو.
٢. هەلبژێرە: زمانێ #C ژ لایێ کیژ کۆمپانیێ ڤە هاتیە چێکرن؟
  • A) Google
  • B) Apple
  • C) Microsoft
  • D) Oracle
بەرسڤا دروست: C) Microsoft
٣. هەلبژێرە: ئێکەم ڤێرژنا زمانێ #C د کیژ ساڵێ دا دەرچوو؟
  • A) 1995
  • B) 2000
  • C) 2002
  • D) 2010
بەرسڤا دروست: C) 2002
٤. ڤالاتیا پڕ بکە: #C ب ________ یان ________ دهێتە خوێندن (Pronounced).
بەرسڤ: C-Sharp ، C-Hash
٥. راست یان خەلەت: #C ل سەر .NET Framework کار دکەت و ژ خێزانا زمانێ Python هاتیە.
بەرسڤ: خەلەت (False) — چونکی ژ خێزانا زمانێ C هاتیە، نە Python.
٦. #C نێزیکی کیژ دوو زمانێن دی یێن بەرنیاسە؟
بەرسڤ: ++C و Java.

سلایدێ ٤: بکارئینانێن #C (C# Applications)

Slide 4

زمانێ #C زمانەکێ گەلەک بهێزە و بۆ چێکرنا ئەڤان جۆرە بەرنامان دهێتە بکارئینان:

  • Mobile applications: بەرنامێن تێلەفۆنێ.
  • Desktop applications: بەرنامێن کۆمپیوتەری.
  • Web applications: بەرنامێن وێبێ.
  • Web services: خزمەتگوزاریێن وێبێ.
  • Web sites: ماڵپەڕ (وێبسایت).
  • Games: یاری (یاریێن ئەلیکترۆنی، وەک ب بزوێنەرێ Unity).
  • VR: ڕاستیا خەیاڵی (Virtual Reality).
  • Database applications: بەرنامێن داتابەیسێ.
  • و گەلەک تشتێن دی ژی!

پسیارێن سلایدێ ٤ (٥ پسیار):

١. پێنج ژ بکارئینانێن زمانێ #C (C# Applications) بژمێرە.
بەرسڤ: ١. Mobile applications، ٢. Desktop applications، ٣. Web applications، ٤. Games، ٥. Database applications (یان Web services, Web sites, VR).
٢. راست یان خەلەت: #C تەنێ بۆ چێکرنا بەرنامێن کۆمپیوتەری (Desktop) دهێتە بکارئینان و بۆ یاریان بکارناهێت.
بەرسڤ: خەلەت (False) — بۆ Games، Mobile، Web، VR و Database ژی دهێتە بکارئینان.
٣. هەلبژێرە: کیژ ژ ئەڤان بکارئینانەکا دروست یا #C یە؟

بەرسڤ: Web applications (یان Web sites/Web services) و Mobile applications.
٥. راست یان خەلەت: #C دکاریت بۆ چێکرنا Database applications و VR بهێتە بکارئینان.

سلایدێ ٥: بۆچی #C دهێتە بکارئینان؟ (Why Use C# ?)

Slide 5

٥ ئەگەرێن سەرەکی کو زمانێ #C گەلەک دهێتە بکارئینان ئەڤەنە:

  1. ئێکە ژ زمانێن پرۆگرامسازیێ یێن هەرە بەرنیاس (Popular) ل جیهانێ.
  2. فێربوونا وی یا بساناهی یە و بکارئینانا وی یا سادەیە (Easy to learn and simple to use).
  3. پشتەڤانیەکا مەزن یا جەماوەری و پرۆگرامەران هەیە (Huge community support).
  4. زمانەکێ Object-Oriented یە کو پێکھاتەیەکێ زەلال (Clear structure) ددەتە پرۆگرامان و ڕێکێ ددەت کۆد دوبارە بهێتە بکارئینان (Code reused)، و ئەڤە ژی تێچوویا گەشەپێدانێ کێم دکەت (Lowering development costs).
  5. چونکی نێزیکی C, ++C و Java یە، بساناهی یە بۆ پرۆگرامەران ژ وان زمانان بچنە سەر #C یان بەروڤاژی (Vice versa).

پسیارێن سلایدێ ٥ (٥ پسیار):

١. سێ ئەگەران بنڤیسە بۆچی #C دهێتە بکارئینان؟ (Why use C#?)
بەرسڤ: ١. فێربوونا وی بساناهی یە و بکارئینانا وی سادەیە. ٢. پشتەڤانیا کۆمەڵگەهەکا مەزن هەیە. ٣. زمانەکێ Object-Oriented یە و کۆد دوبارە تێدا دهێتە بکارئینان و تێچوویێ کێم دکەت.
٢. چەوا بوونا #C ب زمانەکێ Object-Oriented مفای دگەهینیتە کۆمپانی و پرۆگرامەران؟
بەرسڤ: پێکھاتەیەکێ زەلال ددەتە پرۆگرامان و ڕێکێ ددەت کۆد دوبارە بهێتە بکارئینان (Code reused)، ئەڤە ژی تێچوویا گەشەپێدانێ (Development costs) کێم دکەت.
٣. هەلبژێرە: بۆچی بساناهی یە پرۆگرامەرێن C و ++C و Java فێری #C ببن؟
  • A) چونکی چ پەیوەندی ب وان ڤە نینە
  • B) چونکی #C نێزیکی C, ++C و Java یە
  • C) چونکی ب عەرەبی دهێتە نڤیسین
  • D) چونکی تەنێ بۆ وێبێ یە
بەرسڤا دروست: B) چونکی #C نێزیکی C, ++C و Java یە
٤. راست یان خەلەت: #C فێربوونا وی گەلەک ب زەحمەتە و پشتەڤانیا جڤاکی (Community support) یا کێم هەیە.
بەرسڤ: خەلەت (False) — فێربوونا وی بساناهی یە و Huge community support هەیە.
٥. ڤالاتیێ پڕ بکە: ئەو زمانێ ڕێکێ ددەت کۆد دوبارە بهێتە بکارئینان، _________ کێم دکەت.
بەرسڤ: تێچوویا گەشەپێدانێ (Development costs)

سلایدێ ٦: پێکھاتەیێ گشتی یێ #C (C# General Syntax - نەخشە)

Slide 6

ئەڤە قاڵبێ سەرەکی یێ هەر پرۆگرامەکێ #C یە. د وەرەقێ دا گەلەک جاران دهێتە پسیارکرن کو نەخشەیێ کۆدێ #C بنڤیسی یان هەر ڕێزەکێ شروڤە بکەی کا چییە:

using System;                 // ١. ئینانا پەرتووکخانان (Import libraries)

namespace test                // ٢. ناڤێ Namespace (ل ڤێرە ناڤێ وێ test یە)
{
    class Program             // ٣. ناڤێ Class (ل ڤێرە ناڤێ وی Program یە)
    {
        static void Main(string[] args)   // ٤. مێثودێ Main (خاڵا دەستپێکێ)
        {
            C# statements...              // ٥. فەرمان و کۆدێن #C ل ڤێرە دهێنە نڤیسین
        }
    }
}                             // ٦. دوماھیا Namespace (End of the NameSpace)

پسیارێن سلایدێ ٦ (٥ پسیار):

١. پێکھاتەیێ گشتی یێ پرۆگرامێ #C (C# General Syntax) ب ڕێکوپێکی بنڤیسە.
بەرسڤ: 
using System;
namespace test
{
    class Program
    {
        static void Main(string[] args)
        {
            // C# statements
        }
    }
}
٢. د کۆدێ using System; دا، ئەرکێ ئەڤێ ڕێزێ چییە ب گۆرەی نەخشێ سلایدێ ٦؟
بەرسڤ: ئینانا پەرتووکخانێ (Import libraries).
٣. د کۆدێ سلایدێ ٦ دا، ناڤێ namespace چییە و ناڤێ class چییە؟
بەرسڤ: ناڤێ namespace test یە، و ناڤێ class Program یە.
٤. کۆد و فەرمانێن مە (C# statements) د ناڤ کیژ بەشێ پرۆگرامی دا دهێنە نڤیسین؟
بەرسڤ: د ناڤ کڤانێن { } یێن مێثودێ Main (static void Main(string[] args)) دا.
٥. راست یان خەلەت: دوایین کڤانا } د نەخشێ سلایدێ ٦ دا دوماھیا namespace دیار دکەت.
بەرسڤ: راست (True)

سلایدێ ٧: شروڤەکرنا پێکھاتەیێ گشتی (C# General Syntax)

Slide 7

ئەڤ سلایدە گەلەک گرنگە بۆ پسیارێن پێناسە و ئەرکی (What is the function of...):

  • using System: ڕامانا وێ ئەوە ئەم دکارین وان کلاسان (Classes) بکاربینین یێن د ناڤ System namespace دا هەین.
  • namespace: بۆ ڕێکخستنا کۆدێ تە دهێتە بکارئینان، و وەک قووتیکەکێ (Container) یە بۆ کلاسان و namespaceێن دی.
  • کڤانێن پێچاوی {} (Curly braces): دەستپێک و دوماھیا بلۆکەکێ کۆدی (A block of code) نیشان ددەن.
  • class: قووتیکەکە (Container) بۆ داتایان و مێثودان، کو کارکرنێ (Functionality) دئینیتە ناڤ پرۆگرامێ تە. هەر ڕێزەکا کۆدی کو د #C دا کار دکەت دڤێت د ناڤ کلاسەکێ دا بیت. (د نموونێ دا مە ناڤێ کلاسی کرە Program).
  • مێثودێ Main: تشتەکێ دی یە کو هەردەم د پرۆگرامێ #C دا دیار دبیت. هەر کۆدەکێ د ناڤ کڤانێن {} یێن وێ دا بیت دێ هێتە جێبەجێکرن (Executed).

پسیارێن سلایدێ ٧ (٥ پسیار):

١. ئەرکێ using System و namespace چییە؟
بەرسڤ:
• using System: ڕامانا وێ ئەم دکارین کلاسان ژ ناڤ System namespace بکاربینین.
• namespace: بۆ ڕێکخستنا کۆدی دهێتە بکارئینان و Container یە بۆ کلاسان و namespaceێن دی.
٢. ئەرکێ کڤانێن {} (Curly braces) چییە د #C دا؟
بەرسڤ: دەستپێک و دوماھیا بلۆکەکێ کۆدی دیار دکەن (Marks the beginning and the end of a block of code).
٣. پێناسا class بکە د زمانێ #C دا.
بەرسڤ: Container یە بۆ داتایان (data) و مێثودان (methods)، کو کارکرنێ ددەتە پرۆگرامی. هەر ڕێزەکا کۆدی د #C دا کار بکەت دڤێت د ناڤ کلاسەکێ دا بیت.
٤. راست یان خەلەت: د #C دا دشێین ڕێزەکا کۆدی ل دەرڤەی هەمی کلاسان بنڤیسین و کار بکەت (ب گۆرەی سلایدێ ٧).
بەرسڤ: خەلەت (False) — چونکی د سلایدی دا هاتیە: Every line of code that runs in C# must be inside a class.
٥. هەلبژێرە: چ د ناڤ کڤانێن {} یێن مێثودێ Main دا بهێتە نڤیسین چ ب سەری دهێت؟
  • A) دهێتە ژێبرن
  • B) دێ هێتە جێبەجێکرن (Executed)
  • C) دبیتە کۆمێنت
  • D) خەلەتیەکا کۆمپایلەری ددەت
بەرسڤا دروست: B) دێ هێتە جێبەجێکرن (Executed)

سلایدێ ٨: ئێکەم نموونە (First Example)

Slide 8

ئەڤە ئێکەم پرۆگرامێ تەمام یێ #C یە کو پەیڤا Hello World! ل سەر شاشێ چاپ دکەت:

using System;

namespace test
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World!");
        }
    }
}

دەرئەنجام (Output):

Hello World!

تێبینی: ل ڤێرە Console کلاسەکێ ناڤ System یە، و WriteLine مێثودەکە کو دەقی چاپ دکەت.

پسیارێن سلایدێ ٨ (٥ پسیار):

١. پرۆگرامەکێ #C بنڤیسە کو ڕستەیا Hello World! چاپ بکەت.
بەرسڤ: هەمان کۆدێ سلایدێ ٨ (دڤێت using System; و namespace و class و Main و Console.WriteLine("Hello World!"); تێدا بن).
٢. دەرئەنجامێ (Output) کۆدێ ل خوارێ چییە؟ 
Console.WriteLine("Hello Akre!");
بەرسڤ: Hello Akre!
٣. خەلەتیێ د ڤی کۆدی دا ببینە: 
Console.writeline("Hello World!")
بەرسڤ: دوو خەلەتی تێدانە: ١) writeline دڤێت پیتێن W و L مەزن بن (WriteLine). ٢) سیمی کۆڵۆن ; ل دوماهیێ نینە.
٤. راست یان خەلەت: د کۆدێ Console.WriteLine("Hello World!"); دا نیشانێن دوو کۆتەیشن " " ژی ل سەر شاشێ دهێنە چاپکرن.
بەرسڤ: خەلەت (False) — تەنێ دەقێ د ناڤ دا (Hello World!) دهێتە چاپکرن.
٥. ئەگەر using System; ژ سەرێ پرۆگرامێ سلایدێ ٨ بهێتە لادان و Console.WriteLine ب تنێ بهێتە نڤیسین، چ ڕووددەت؟
بەرسڤ: کۆمپایلەر دێ خەلەتیێ (Error) دەت چونکی Console د ناڤ System دایە.

سلایدێ ٩: تێبینیێن گشتی (General Notes)

Slide 9

ئەڤ ٥ تێبینیێن گشتی گەلەک د گرنگن و هەردەم د تاقیکرنان دا ژێ دهێن:

  1. #C هەستیارە بۆ پیتێن مەزن و بچووک (Case sensitive): پیتا a جودایە ژ A.
  2. هەمی فەرمان و دەربڕین (Statements & expressions) دڤێت ب سیمی کۆڵۆن ; ب دوماهی بهێن.
  3. جێبەجێکرنا پرۆگرامی (Execution) ژ مێثودێ Main دەستپێدکەت.
  4. بەروڤاژی زمانێ Java: د #C دا ناڤێ فایلێ پرۆگرامی دشێت جودا بیت ژ ناڤێ کلاسی (Program file name could be different from the class name).
  5. Console.ReadKey(): دشێت ل دوماهیێ بهێتە زێدەکرن. ئەڤە وەدکەت پرۆگرام ل هیڤیا لێدانا کلیلەکی (Key press) ڕاوەستیت و ڕێگریێ دکەت کو شاشە ب لەز ڤەبیت و بێتە گرتن دەما پرۆگرام ژ Visual Studio .NET دهێتە کارپێکرن.

پسیارێن سلایدێ ٩ (٥ پسیار):

١. ئەرکێ فەرمانا Console.ReadKey() چییە ل دوماھیا پرۆگرامێ #C؟
بەرسڤ: پرۆگرام ل هیڤیا لێدانا کلیلەکی (Key press) دمینیت و ناهێلیت شاشا دەرئەنجامی ب لەز بێتە گرتن دەما ژ Visual Studio .NET دهێتە کارپێکرن.
٢. جیاوازیا د ناڤبەرا #C و Java دا چییە دەربارەی ناڤێ فایلی و ناڤێ کلاسی؟
بەرسڤ: بەروڤاژی Java، د #C دا ناڤێ فایلێ پرۆگرامی دشێت جودا بیت ژ ناڤێ کلاسی (Could be different from the class name).
٣. ڤالاتیێ پڕ بکە: جێبەجێکرنا پرۆگرامێ #C ژ مێثودێ _________ دەستپێدکەت.
بەرسڤ: Main
٤. هەلبژێرە: هەمی Statements و Expressions د #C دا دڤێت ب چ ب دوماهی بهێن؟
  • A) : (Colon)
  • B) . (Dot)
  • C) ; (Semicolon)
  • D) , (Comma)
بەرسڤا دروست: C) ; (Semicolon)
٥. راست یان خەلەت: #C زمانەکێ Case sensitive نینە، واتە a و A وەکی ئێکن.
بەرسڤ: خەلەت (False) — #C زمانەکێ Case sensitive یە، a جودایە ژ A.

سلایدێ ١٠: جیاوازیا WriteLine و Write د #C دا

Slide 10

مێثودێ هەرە بەربەلاڤ بۆ چاپکرنێ د #C دا WriteLine() یە، بەلێ تو دشێی Write() ژی بکاربینی.

جیاوازیا د ناڤبەرا وان دا:

  • WriteLine(): هەر جارەکا چاپ دکەت، دەقی ل سەر ڕێزەکا نوی (New line) دئینیتە خوارێ (پشتی چاپکرنێ Enter لێ ددەت).
  • Write(): ل سەر هەمان ڕێزێ (Same line) چاپ دکەت و ناچیتە ڕێزا نوی.

نموونە:

Console.WriteLine("Hello World!");
Console.WriteLine("I will print on a new line.");
Console.Write("Hello World! ");
Console.Write("I will print on the same line.");

دەرئەنجام (Result):

Hello World!
I will print on a new line.
Hello World! I will print on the same line.

پسیارێن سلایدێ ١٠ (٥ پسیار):

١. جیاوازیا د ناڤبەرا Console.WriteLine() و Console.Write() دا چییە؟
بەرسڤ: WriteLine() هەر جارەکی دەرئەنجامی ل سەر ڕێزەکا نوی چاپ دکەت، بەلێ Write() ل سەر هەمان ڕێزێ چاپ دکەت.
٢. دەرئەنجامێ (Output) ئەڤی کۆدی بنڤیسە وەک یێ سەر شاشێ: 
Console.Write("Akre ");
Console.WriteLine("IT");
Console.Write("Dept");
بەرسڤ:
Akre IT
Dept
(تێبینی: چونکی ڕێزا ئێکێ Write بوو، IT چوو تەنیشتا Akre، بەلێ پاشی WriteLine چوو ڕێزا نوی بۆ Dept!)
٣. دەرئەنجامێ ئەڤی کۆدی چییە؟ 
Console.Write("A");
Console.Write("B");
Console.Write("C");
بەرسڤ: ABC (هەمی ل سەر ئێک ڕێز دبن).
٤. هەلبژێرە: مێثودێ هەرە بەربەلاڤ بۆ چاپکرنێ (Output) د #C دا کیژە؟
  • A) Print()
  • B) WriteLine()
  • C) ReadKey()
  • D) Output()
بەرسڤا دروست: B) WriteLine()
٥. راست یان خەلەت: Console.Write() پشتی چاپکرنێ دهێتە سەر ڕێزەکا نوی.
بەرسڤ: خەلەت (False) — ل سەر هەمان ڕێزێ دمینیت.

سلایدێ ١١: کۆمێنت د #C دا (C# Comments)

Slide 11

بۆچی کۆمێنت دهێنە بکارئینان؟

  • بۆ شروڤەکرنا کۆدێ #C و زێدەکرنا تێگەهشتنێ (Make it more readable).
  • بۆ ڕێگریکرن ژ جێبەجێبوونا کۆدەکی دەما ئەم کۆدەکێ دی تاقی دکەین (Prevent execution when testing alternative code).

جۆرێن کۆمێنتان د #C دا دوو جۆرن:

  1. کۆمێنتا ئێک-ڕێز (Single-line comments): ب دوو فۆرۆرد سلاش // دەستپێدکەت. 
    // This is a comment
Console.WriteLine("Hello World!"); // This is another comment
  2. کۆمێنتا چەند-ڕێزی (Multi-line comments): ب /* دەستپێدکەت و ب */ ب دوماهی دهێت. 
    /* The code below will print the words Hello World to the 
screen, and it is amazing */
Console.WriteLine("Hello World!");

پسیارێن سلایدێ ١١ (٥ پسیار):

١. دوو مفایێن بکارئینانا کۆمێنتان د #C دا بنڤیسە.
بەرسڤ: ١. بۆ شروڤەکرنا کۆدی و بساناهیکرنا خواندنا وی. ٢. بۆ ڕێگریکرن ژ جێبەجێکرنا کۆدەکی دەما کۆدەکێ دی دهێتە تاقیکرن.
٢. جۆرێن کۆمێنتان د #C دا چنە دگەل نیشانا هەر ئێکێ؟
بەرسڤ: ١. Single-line comments ب // دەستپێدکەت. ٢. Multi-line comments ب /* دەستپێدکەت و ب */ ب دوماهی دهێت.
٣. دەرئەنجامێ (Output) ئەڤی کۆدی چییە؟ 
// Console.WriteLine("One");
Console.WriteLine("Two");
/* Console.WriteLine("Three"); */
بەرسڤ: تەنێ Two چاپ دبیت، چونکی ڕێزا ئێکێ و سێیێ کۆمێنتن و جێبەجێ نابن.
٤. هەلبژێرە: کۆمێنتا چەند-ڕێزی (Multi-line) ب چ دەستپێدکەت و ب چ دگریت؟
  • A) // ... //
  • B) /* ... */
  • C) # ... #
  • D) <!-- ... -->
بەرسڤا دروست: B) /* ... */
٥. راست یان خەلەت: ناهێتە رێپێدان کۆمێنت د هەمان ڕێزێ دا پشتی فەرمانا Console.WriteLine("Hello"); بهێتە نڤیسین.
بەرسڤ: خەلەت (False) — دروستە د پشت سیمی کۆڵۆنێ دا بهێتە نڤیسین وەک Console.WriteLine("Hello"); // comment.

سلایدێ ١٢: گۆڕاو و جۆرێن داتایان (C# Variables)

Slide 12

گۆڕاو (Variables): قووتیک یان دەفرن بۆ هەڵگرتنا بهایێن داتایان (Containers for storing data values). د #C دا جۆرێن جودا یێن گۆڕاوان هەنە:

جۆر (Type) چ هەڵدگریت؟ نموونە تێبینیەکا گرنگ
int ژمارێن تەمام (بێ پۆینت / فاریزە) 123 یان -123 دەعیمال (پۆینت) نابت تێدا بیت
double ژمارێن ب پۆینت (Floating point) 19.99 یان -19.99 پۆینت تێدا هەیە
char ئێک پیت یان ئێک نیشان (Single character) 'a' یان 'B' د ناڤ تاک کۆتەیشن ' ' دا
string دەق و ڕستە (Text) "Hello World" د ناڤ دوو کۆتەیشن " " دا
bool دوو حالەت هەنە: راست یان خەلەت true یان false ب بێ کۆتەیشن دهێتە نڤیسین

پسیارێن سلایدێ ١٢ (٦ پسیار):

١. پێناسا Variables بکە و ٥ جۆرێن سەرەکی (Basic value types) دگەل نموونێ هەر ئێکی بنڤیسە.
بەرسڤ: Variables قووتیکن بۆ هەڵگرتنا بهایێن داتایان. پێنج جۆر: int (123)، double (19.99)، char ('a')، string ("Hello")، bool (true).
٢. جیاوازیا د ناڤبەرا char و string دا چییە؟
بەرسڤ: char تەنێ ئێک پیت/نیشان هەڵدگریت و د ناڤ تاک کۆتەیشن ' ' دایە، بەلێ string دەقان هەڵدگریت و د ناڤ دوو کۆتەیشن " " دایە.
٣. هەلبژێرە: کیژ جۆرێ گۆڕاوی بۆ هەڵگرتنا ژمارا -19.99 یێ گونجایە؟
  • A) int
  • B) double
  • C) char
  • D) bool
بەرسڤا دروست: B) double
٤. خەلەتیێ د ئەڤێ ڕێزا کۆدی دا ببینە: char grade = "A";
بەرسڤ: بهایێ char دڤێت د ناڤ تاک کۆتەیشن دا بیت، واتە 'A' نەک "A".
٥. ڤالاتیێ پڕ بکە: جۆرێ bool بهایان ب دوو حالەتان هەڵدگریت کو ئەو ژی _________ یان _________ نە.
بەرسڤ: true ، false
٦. راست یان خەلەت: جۆرێ int ژمارێن نێگەتیڤ (وەک -123) هەڵناگریت.
بەرسڤ: خەلەت (False) — int ژمارێن تەمام یێن پۆزەتیڤ و نێگەتیڤ هەردووکان هەڵدگریت (وەک 123 یان -123).

سلایدێ ١٣: دروستکرنا گۆڕاوان و نەگۆڕان (Variables & Constants)

Slide 13

١. شێوازێ دروستکرنا گۆڕاوی (Declaring Variables):

type variableName = value;

نموونە:

string name = "John";
int myNum = 15;
myNum = 20; // ل ڤێرە بهایێ myNum بوو 20 چونکی گۆڕاوە

٢. نەگۆڕ (Constants - const):

  • ئەگەر تە نەڤێت بهایێ گۆڕاوی د پاشەڕۆژێ دا بهێتە گوهۆڕین، پەیڤا const ل پێشیا جۆرێ وی بنڤیسە.
  • ئەڤە گۆڕاوی دکەتە Unchangeable و Read-only (تەنێ بۆ خوێندنێ یە و ناهێتە گوهۆڕین).
  • تێبینیەکا گرنگ: دەمێ const چێدکەی، دڤێت د هەمان ڕێزێ دا بهایەکێ بدەیێ، و بێی بها ناهێتە چێکرن.
const int myNum = 15;
myNum = 20; // خەلەتی (Error) دەت چونکی const ناگوهۆڕیت!

پسیارێن سلایدێ ١٣ (٥ پسیار):

١. پەیڤا const بۆ چ دهێتە بکارئینان د #C دا؟
بەرسڤ: بۆ دروستکرنا نەگۆڕی (Constant) دهێتە بکارئینان دا کو بها نەگوهۆڕیت (Unchangeable and Read-only).
٢. دەرئەنجامێ ئەڤی کۆدی چییە؟ 
const int x = 10;
x = 25;
Console.WriteLine(x);
بەرسڤ: خەلەتی (Error) ددەت، چونکی نەگۆڕ (const) ناهێتە گوهۆڕین.
٣. شێوازێ گشتی (Syntax) یێ دروستکرنا گۆڕاوەکی بنڤیسە و نموونەیەکێ بۆ string بدە.
بەرسڤ: type variableName = value; — نموونە: string name = "Ali";
٤. هەلبژێرە: کیژ ژ ئەڤان دروستە بۆ پێناسەکرنا نەگۆڕەکی؟
  • A) constant int x = 5;
  • B) const int x = 5;
  • C) int const x; x = 5;
  • D) final int x = 5;
بەرسڤا دروست: B) const int x = 5;
٥. راست یان خەلەت: دشێین گۆڕاوەکێ const بێی بها دروست بکەین و پاشی بهایەکی بدەینێ.
بەرسڤ: خەلەت (False) — دەمێ const دهێتە دروستکرن، دڤێت د هەمان دەم دا بهایێ خۆ وەربگریت.

سلایدێ ١٤: پەیڤێن پاراستی و ناڤلێنان (Keywords & Identifiers)

Slide 14

١. پەیڤێن پاراستی (C# Keywords / Reserved Words):

پەیڤێن تایبەتن کو کۆمپایلەرێ #C وان دناسێت و واتایا تایبەت د زمانێ #C دا هەیە. نابیت وەک ناڤێ گۆڕاوان (Identifiers) بهێنە بکارئینان (وەک: int، double، class، using، namespace، const، void، static، true، false).

٢. ناڤلێنان (C# Identifiers):

هەمی گۆڕاو (Variables) دڤێت ب ناڤێن تاک (Unique names) بهێنە نیاسین، ئەڤ ناڤە دبێژنێ Identifiers (وەک x، age، minutesPerHour).

مەرج و ڕێسایێن گشتی یێن نڤیسینا Identifiers:

  • ناڤ دشێت پیت (Letters)، ژمارە (Digits)، و نیشانا ئەندەرسکۆر (_) تێدا بن.
  • ناڤ دڤێت ب پیتەکێ یان _ دەستپێبکەت (نابیت ب ژمارە دەستپێبکەت!).
  • باشترە ناڤ ب پیتەکا بچووک دەستپێبکەت و نابیت ڤالاتی (Whitespace/Space) تێدا بیت.
  • ناڤ هەستیارن بۆ پیتێن مەزن و بچووک (myVar و myvar دوو ناڤێن جودانە).
  • پەیڤێن پاراستی (Keywords وەک int یان double) نابنە ناڤ.

پسیارێن سلایدێ ١٤ (٥ پسیار):

١. پێناسا Identifiers و Keywords بکە د زمانێ #C دا.
بەرسڤ: Identifiers ئەو ناڤێن تاکن یێن دهێنە دان بۆ گۆڕاو و کلاسان. Keywords ئەو پەیڤێن پاراستینە کو واتایا تایبەت بۆ کۆمپایلەری هەیە و نابنە ناڤێ گۆڕاوان.
٢. هەلبژێرە: کیژ ژ ئەڤان ناڤان بۆ گۆڕاوی (Identifier) خەلەتە؟
  • A) _age
  • B) user1
  • C) 1user
  • D) my_Name
بەرسڤا دروست: C) 1user (چونکی ب ژمارە دەستپێکرییە).
٣. سێ مەرجان ژ ڕێسایێن ناڤلێنانا Identifiers بنڤیسە.
بەرسڤ: ١. ب پیت یان ئەندەرسکۆر (_) دەستپێدکەت و نابیت ب ژمارە دەستپێبکەت. ٢. نابیت ڤالاتی (Space) تێدا بیت. ٣. نابیت Keyword بیت و Case sensitive یە.
٤. بۆچی ناهێتە رێپێدان بنڤیسین int class = 5; ؟
بەرسڤ: چونکی class پەیڤەکا پاراستی (Keyword) یە د #C دا و نابیت ببیتە ناڤێ گۆڕاوی.
٥. راست یان خەلەت: ناڤێ my Age وەک ناڤێ گۆڕاوی دروستە، و age و Age هەمان تشتن.
بەرسڤ: خەلەت (False) — ڤالاتی د ناڤ my Age دا قەدەغەیە، هەروەسا age و Age ژ بەر Case sensitivity ژ ئێک جودانە.

تاقیکرنا گشتی یا نەزەری (نموونا پسیارێن سەر وەرەقێ)

Final Exam Practice

ئەڤ تاقیکرنە هەمی سلایدان ب خۆ ڤە دگریت دا خۆ بۆ رۆژا تاقیکرنێ تاقی بکەی:

پ١. پرۆگرامەکێ #C یێ تەمام بنڤیسە کو دوو گۆڕاوان چێبکەت: یێ ئێکێ ناڤێ تە ب جۆرێ string، یێ دووێ ژی ژمارەکا نەگۆڕ (const) یا ساڵا ٢٠٢٦ ب جۆرێ int، و هەردووکان چاپ بکەت.
بەرسڤا نموونەیی: 
using System;

namespace test
{
    class Program
    {
        static void Main(string[] args)
        {
            string name = "Ahmed";
            const int year = 2026;
            Console.WriteLine(name);
            Console.WriteLine(year);
        }
    }
}
پ٢. دەرئەنجامێ (Output) ئەڤی کۆدی وەک خۆ بنڤیسە: <

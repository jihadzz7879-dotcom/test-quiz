نموونەیێن ژمارەیان: پێڤانا دەمێ و وردبینیا PI (π) سلاید ٧ و ٨

نموونەیا سلاید ٧ (Measuring Time): ل دویڤ یەکەیا پێڤانێ ئەم جۆرێن جودا یێن ژمارەیان بکاردهینین:

byte centuries = 20;     // ژمارەیەکا بچووک (0..255)
ushort years = 2000;     // ژمارەیەکا ناڤنجی (0..65,535)
uint days = 730480;
ulong hours = 17531520;  // دبیت ژمارە گەلەک مەزن بیت
Console.WriteLine("{0} centuries is {1} years, or {2} days, or {3} hours.",
                  centuries, years, days, hours);
Console.ReadKey();
ئەنجام (Result):
20 centuries is 2000 years, or 730480 days, or 17531520 hours.

نموونەیا سلاید ٨ (PI precision): جیاوازی د ناڤبەرا float و double دا:

float floatPI = 3.141592653589793238f;
double doublePI = 3.141592653589793238;
Console.WriteLine("Float PI is: {0}", floatPI);
Console.WriteLine("Double PI is: {0}", doublePI);
Console.ReadKey();
ئەنجام (Result):
Float PI is: 3.141593 Double PI is: 3.14159265358979
⚠️ تێبینیا گرنگ ژ سلایدێ ٨: د C# دا هەر ژمارەیەکا ب پۆینت (Real number) ب شێوەیێ خۆکارانە (Default) وەک double دهێتە خواندن! ئەگەر تە پیتا f ل دووماهییا 3.14f نەنڤیسی، کۆمپایلەر دێ خەلەتیێ (Error) دەت! وە د ئەنجامیدا float ژمارە ڕووند کر بۆ 3.141593 (تەنها ٧ ژماران)، بەلێ double ١٥ ژماران نیشان دا.

جۆرێن Boolean، Char و String سلاید ٩، ١٠ و ١١

١. Boolean (سلاید ٩): ب پەیڤا bool دهێتە راگەهاندن، بتنێ دوو نرخ هەنە: true یان false. نرخێ بنەڕەتی (Default) falseـە.

int a = 1;
int b = 2;
bool greaterAB = (a > b);
Console.WriteLine(greaterAB); // False
bool equalA1 = (a == 1);
Console.WriteLine(equalA1);   // True

٢. Char (سلاید ١٠): بۆ خەزنکرنا ئێک پیت د ناڤ تاکە قەوسان دا ('A'). نرخێ بنەڕەتی (Default) بریتییە ژ '\0'.

char myGrade = 'B';
Console.WriteLine(myGrade); // B

٣. String (سلاید ١١): بۆ خەزنکرنا زنجیرەکا پیتان (نڤیسین) د ناڤ جۆت قەوسان دا ("..."). نرخێ بنەڕەتی nullـە. ب نیشانا + دوو سترینگ پێکڤە دهێنە گرێدان (Concatenation)، و \n هێلەکا نوی (New line) چێدکەت.

string firstName = "Dareen";
string lastName = "Muhammed";
Console.WriteLine("Hello, {0}!\n", firstName);
string fullName = firstName + " " + lastName;
Console.WriteLine("Your full name is {0}.", fullName);
ئەنجام (Result):
Hello, Dareen! Your full name is Dareen Muhammed.
⚠️ تێبینیا ئەزموونێ بۆ سلاید ٩-١١: • دەمێ Console.WriteLine نرخەکێ bool چاپ دکەت، ب پیتا مەزن دەردکەڤیت: True یان False.
• جیاوازیا نرخێن بنەڕەتی (Default Values) ژبەر بکە: bool ➔ false | char ➔ '\0' | string ➔ null.
• تەماشەی \n بکە د ناڤ WriteLine دا: WriteLine بخۆ دچیتە ڕێزا نوی، و \n ژی دچیتە ڕێزەکا دی، لەوما ڕێزەکا ڤاڵا د ناڤبەرێدا چێدبیت!

ئۆپەرەیتەرێن C# و ئۆپەرەیتەرێن بیرکاری (Arithmetic) سلاید ١٢، ١٣ و ١٤

سلاید ١٢ (Categories of operators): ئۆپەرەیتەرێن C# ئەڤ گرۆپەنە:

  • Arithmetic: + - * / % ++ --
  • Logical: && || ^ !
  • Binary (Bitwise): & | ^ ~ << >>
  • Comparison: == != < > <= >=
  • Assignment: = += -= *= /= %= &= |= ^= <<= >>=
  • String Concatenation: +
  • Type conversion: is as typeof
  • Others: . [] () ?: new

سلاید ١٣ (Arithmetic Operators):

  • + کۆمکرن | - لێدەرکردن | * لێکدان | / دابەشکرن
  • % (Remainder): ماوێ دابەشکرنێ (بۆ نموونە 5 % 2 = 1).
  • ++ نرخێ گوهۆڕێ ب ١ زێدە دکەت | -- ب ١ کێم دکەت.
  • +5 (Unary plus) و -5 (Unary minus: ژمارێ دکەتە نێگەتیڤ).

سلاید ١٤ (نموونەیا پراکتیکی - گەلەک گرنگە!):

int squarePerimeter = 17;
double squareSide = squarePerimeter / 4.0;  // 4.25 چونکی 4.0 doubleـە
double squareArea = squareSide * squareSide; // 18.0625
Console.WriteLine(squareSide);  // 4.25
Console.WriteLine(squareArea);  // 18.0625

int a = 5;
int b = 4;
Console.WriteLine(a + b);     // 9
Console.WriteLine(a + b++);   // 9  (بەراهیێ b=4 کۆم دکەت، پاشان b دبیتە 5!)
Console.WriteLine(a + b);     // 10 (ئەڤجا b=5ـە، 5+5=10)
Console.WriteLine(a + (++b)); // 11 (بەراهیێ b دبیتە 6، پاشان 5+6=11!)
Console.WriteLine(a + b);     // 11
Console.WriteLine(11 / 3);    // 3  (دابەشکرنا int پۆینتی دەردهاڤێژیت!)
Console.WriteLine(11 % 3);    // 2  (ماوێ 11 لسەر 3 = 2، چونکی 3*3=9، 11-9=2)
Console.WriteLine(12 / 3);    // 4
⚠️ تێبینیا ئەزموونێ (ب هشیاری ڤان سێ خاڵان بخوینە!): 1️⃣ Post-increment (b++): بەراهیێ نرخێ کەڤن یێ b د ناڤ هاوکێشێدا بکاردهینیت، پاشان ١ لسەر زێدە دکەت.
2️⃣ Pre-increment (++b): بەراهیێ ١ لسەر b زێدە دکەت، پاشان نرخێ نوی بکاردهینیت.
3️⃣ Integer Division: 11 / 3 د C# دا ئەنجامێ وێ 3ـە نەک 3.66، چونکی هەردوو intـن! بەلێ 17 / 4.0 ئەنجامێ وێ 4.25ـە چونکی 4.0 ژ جۆرێ doubleـە.

شڕۆڤەکرنا ئەنجامێن سلاید ١٦ (گەلەک گرنگە!):

int a = 21;
int c;
c = a;     // Line 1: c = 21
c += a;    // Line 2: c = 21 + 21 = 42
c -= a;    // Line 3: c = 42 - 21 = 21
c *= a;    // Line 4: c = 21 * 21 = 441
c /= a;    // Line 5: c = 441 / 21 = 21
c = 200;
c %= a;    // Line 6: c = 200 % 21 = 11  (چونکی 21*9=189، 200-189=11)
c <<= 2;   // Line 7: 11 (1011) لێدانا چەپێ ب 2 بت ➔ 44 (101100)
c >>= 2;   // Line 8: 44 لێدانا راستێ ب 2 بت ➔ 11
c &= 2;    // Line 9: 11 (1011) & 2 (0010) ➔ 0010 = 2
c ^= 2;    // Line 10: 2 (0010) ^ 2 (0010) ➔ 0000 = 0
c |= 2;    // Line 11: 0 (0000) | 2 (0010) ➔ 0010 = 2

ئۆپەرەیتەرێن بەراوردکرنێ (Comparison Operators) سلاید ١٩ و ٢٠

ئەڤ ئۆپەرەیتەرە دوو نرخان بەراورد دکەن و ئەنجامێ وان هەردەم True یان Falseـە:

  • == یەکسانە ب | != یەکسان نینە ب
  • > مەزنترە ژ | < بچووکترە ژ
  • >= مەزنترە یان یەکسانە | <= بچووکترە یان یەکسانە

نموونەیا سلاید ٢٠ (گەلەک فێڵ تێدایە، ئاگەهدار بە!):

int a = 5;
int b = 4;
Console.WriteLine(a >= b);   // True  (5 >= 4)
Console.WriteLine(a != b);   // True  (5 != 4)
Console.WriteLine(a == b);   // False (5 == 4)
Console.WriteLine(a != ++b); // False! (چونکی ++b بەراهیێ b دکەتە 5، پاشان 5 != 5 دبیتە False!)
Console.WriteLine(a > b);    // False! (چونکی b نها 5ـە، و 5 > 5 خەلەتە!)
⚠️ تێبینیا ئەزموونێ بۆ سلاید ٢٠: ل ڤان هەردوو ڕێزێن دووماهیێ بباشی تەماشە بکە: a != ++b و a > b! گەلەک قوتابی هزر دکەن b هێشتا 4ـە، بەلێ ژ بەر ++b، b بوو 5، لەوما هەردوو ڕێزێن دووماهیێ بووینە False! هەروەسا = ئۆپەرەیتەرێ پێدانێ یە (Assignment) بەلێ == بۆ بەراوردکرنێ یە!
📝 ئەزموونا سلاید ١٩ و ٢٠
راست و خەلەت
١. د C# دا هێمایا = بۆ پشکنینا یەکسانیێ د ناڤبەرا دوو نرخان دا دهێتە بکارهینان.
نڤیسین
٢. ئەگەر int x = 8; int y = 7; بن، ئەنجامێ Console.WriteLine(x == ++y); دێ چ بیت؟
ئۆپەرەیتەرێن لۆژیکی (Logical Operators) سلاید ٢١ و ٢٢

ئەڤ ئۆپەرەیتەرە نرخێن Boolean (true/false) وەردگرن و true/false دزڤڕینن:

  • && (Logical AND): بتنێ دەمێ هەردوو لایەن true بن، ئەنجام trueـە.
  • || (Logical OR): ئەگەر هەر ئێک ژ لایەنان true بیت، ئەنجام trueـە.
  • ! (Logical NOT): بەروڤاژی دکەت (!true = false و !false = true).
  • ^ (Logical XOR): ئەگەر هەردوو لایەن ژ ئێک جودا بن (ئێک true و ئێک false) ئەنجام trueـە، ئەگەر وەکی ئێک بن falseـە!
bool a = true;
bool b = false;
Console.WriteLine(a && b);              // False
Console.WriteLine(a || b);              // True
Console.WriteLine(a ^ b);               // True  (جودانە: true و false)
Console.WriteLine(!b);                  // True
Console.WriteLine(b || true);           // True
Console.WriteLine(b && true);           // False
Console.WriteLine(a || true);           // True
Console.WriteLine(a && true);           // True
Console.WriteLine(!a);                  // False
Console.WriteLine((5 > 7) ^ (a == b));  // False (چونکی false ^ false = False)
⚠️ تێبینیا زێڕین بۆ ^ (XOR): د سلایدێ ٢٢ دا رێزا دووماهیێ (5 > 7) ^ (a == b): 5 > 7 دبیتە false، و a == b (true == false) دبیتە false. و د XOR دا false ^ false = False (چونکی هەردوو وەکی ئێکن!).
📝 ئەزموونا سلاید ٢١ و ٢٢
هەلبژارتن
١. ئەنجامێ (true ^ true) چییە؟
نڤیسین
٢. ئەنجامێ !(5 < 10 && 3 > 8) چ دەرکەڤیت؟
ئۆپەرەیتەرێن بیتی (Bitwise Operators) سلاید ٢٣ و ٢٤

ئۆپەرەیتەرێن Bitwise ل سەر ژمارێن تەمام (وەک byte, sbyte, int, uint, long, ulong, ushort) کار دکەن و بت ب بت (bit by bit) ل دویڤ سیستەمێ دوویی (Binary: 0 و 1) کارێ خۆ دکەن:

  • ~ هەمی 0 دکەتە 1 و هەمی 1 دکەتە 0.
  • | (OR): ئەگەر ئێک ژ بتان 1 بیت ئەنجام 1ـە.
  • & (AND): بتنێ ئەگەر هەردوو بت 1 بن ئەنجام 1ـە.
  • ^ (XOR): ئەگەر بت جودا بن (1 و 0) ئەنجام 1ـە.
  • << (Left shift): بتان بۆ لایێ چەپێ دهەلینیت (وەک لێکدانا ب ٢).
  • >> (Right shift): بتان بۆ لایێ راستێ دهەلینیت (وەک دابەشکرنا ب ٢).
ushort a = 3; // 00000000 00000011
ushort b = 5; // 00000000 00000101

Console.WriteLine(a | b);   // 00000111 ➔ 7
Console.WriteLine(a & b);   // 00000001 ➔ 1
Console.WriteLine(a ^ b);   // 00000110 ➔ 6
Console.WriteLine(~a & b);  // 00000100 ➔ 4
Console.WriteLine(a << 1);  // 00000110 ➔ 6  (3 * 2 = 6)
Console.WriteLine(a >> 1);  // 00000001 ➔ 1  (3 / 2 = 1)
⚠️ تێبینیا ئەزموونێ بۆ سلاید ٢٤: بۆ ل سەر وەرەقێ، هەردەم ژمارێ بکە باینەری (8-4-2-1):
• 3 = 0011 و 5 = 0101.
• د ~a & b دا: ~3 هەمی بتان بەروڤاژی دکەت (...11111100)، پاشان دگەل 5 (...00000101) ب AND دەرکەڤیتە 0100 کو دبیتە 4!
📝 ئەزموونا سلاید ٢٣ و ٢٤
هەلبژارتن
١. ئەگەر ushort a = 3; ushort b = 5; بن، ئەنجامێ a ^ b چەندە؟
نڤیسین
٢. ئەگەر int x = 6; بیت، ئەنجامێ x << 1 چەندە؟
ئۆپەرەیتەرێن دی (String Concatenation, Conditional ?:, new, typeof, is) سلاید ٢٥ و ٢٦

سلاید ٢٥ (String Concatenation +):

  • بۆ پێکڤەگرێدانا دوو سترینگان دهێتە بکارهینان.
  • ئەگەر لایەنێ دووێ سترینگ نەبیت (وەک int)، ب شێوەیێ خۆکارانە دبیتە سترینگ!
string first = "First";

string output = "The number is : ";

گوهۆڕینا جۆرێ داتایان (Type Casting & Type Conversion) سلاید ٢٧ و ٢٨

سلاید ٢٧ (C# Type Casting): گوهۆڕینا نرخێ جۆرەکێ داتایێ بۆ جۆرەکێ دی، دوو جۆر هەنە:

  • Implicit Casting (خۆکارانە / بچووک بۆ مەزن):
    char -> int -> long -> float -> double
  • Explicit Casting (دەستی / مەزن بۆ بچووک): دڤێت ب دەست د ناڤ کەواناندا جۆرێ مەبەست بنڤیسی.
    double -> float -> long -> int -> char
// Implicit Casting:
int myInt = 9;
double myDouble = myInt;       // خۆکارانە int دبیتە double
Console.WriteLine(myInt);      // 9
Console.WriteLine(myDouble);   // 9

// Explicit Casting:
double myDouble2 = 9.78;
int myInt2 = (int) myDouble2;  // ب دەست double دبیتە int (پۆینتێ لاددەت!)
Console.WriteLine(myDouble2);  // 9.78
Console.WriteLine(myInt2);     // 9

سلاید ٢٨ (C# Type Conversion): گوهۆڕین ب ڕێکا میسۆدێن ئامادەکری یێن Convert:

  • Convert.ToBoolean
  • Convert.ToDouble
  • Convert.ToString
  • Convert.ToInt32 (بۆ int)
  • Convert.ToInt64 (بۆ long)
int myInt = 10;
double myDouble = 5.25;
bool myBool = true;

Console.WriteLine(Convert.ToString(myInt));   // "10"
Console.WriteLine(Convert.ToDouble(myInt));   // 10
Console.WriteLine(Convert.ToInt32(myDouble)); // 5
Console.WriteLine(Convert.ToString(myBool));  // "True"
⚠️ تێبینیا زێڕین بۆ سلاید ٢٧ و ٢٨: • ئەگەر گۆت int بۆ double ➔ ئەڤە Implicitـە (خۆکارانە، بێ کەوانە).
• ئەگەر گۆت double بۆ int ➔ ئەڤە Explicitـە (ب دەست، دڤێت (int) بنڤیسی، و ژمارا پشتی پۆینتێ تەلەف دبیت: 9.78 دبیتە 9 نەک 10!).
• د Convert دا ژبیر نەکە: ToInt32 بۆ intـە (چونکی int 32-bitـە) و ToInt64 بۆ longـە (چونکی long 64-bitـە)!

نڤیسین

دەربڕینێن C# (C# Expressions) سلاید ٢٩

Expressions (دەربڕین): زنجیرەیەکن ژ ئۆپەرەیتەران، نرخان (literals) و گوهۆڕان (variables) کو دهێنە هژمارتن بۆ نرخەکێ دیارکری. هەر دەربڕینەکێ Type (جۆر: integer, real, Boolean...) و Value (نرخ) هەیە.

// نموونەیا ١:
int r = (150 - 20) / 2 + 5; // 130 / 2 + 5 = 65 + 5 = 70
Console.WriteLine(r);       // 70

// نموونەیا ٢:
int a = 2 + 3;                                 // a = 5
int b = (a + 3) * (a - 4) + (2 * a + 7) / 4;   // b = 12
bool g = (a > b) || ((a == 0) && (b == 0));    // g = False
Console.WriteLine(" a is= " + a);
Console.WriteLine(" b is= " + b);
Console.WriteLine(" g is= " + g);

هژمارتنا b ب هێمنی و هەنگاڤ ب هەنگاڤ:

  • a = 5
  • (a + 3) = (5 + 3) = 8
  • (a - 4) = (5 - 4) = 1
  • (2 * a + 7) = (10 + 7) = 17
  • 17 / 4 = 4 (بێ پۆینت چونکی هەردوو intـن!)
  • کۆمکرن: 8 * 1 + 4 = 8 + 4 = 12!
  • بۆ g: (5 > 12) خەلەتە، (5 == 0) خەلەتە، لەوما false || false = False!

نڤیسین

پێشەکی، پێکهاتە و جۆرێن سەرەکی یێن داتایان (C# Data Types)

📌 سڵاید ١ و ٢: بابەتێن سەرەکی (Outlines)

  • پێنج تەوەرێن سەرەکی د ڤێ لێکچەرێ دا هەنە: Data Types (جۆرێن داتایان)، Operators (ئۆپەرەیتەر)، Type Casting، Type Conversion، و Expressions (دەربڕین).

📌 سڵاید ٣: زمانێ C# و گرنگییا Data Type

  • C# زمانەکێ Strongly-typedـە: یانی بەری تو هەر گوهۆڕەکێ (Variable) بکاربینی، دڤێت جۆرێ وی دیار بکەی کا دێ چ تێدا هێتە هەلگرتن.
  • Data Type قەبارێ مێمۆریێ (Size) و جۆرێ بهایێ گوهۆڕی دیار دکەت.
  • بۆچی گرنگە جۆرێ دروست هەلبژێرین؟ (پسیارا گرنگ یا وەرەقەی!):
    1. دا خەلەتی (Errors) چێنەبن.
    2. دا دەم و مێمۆری (Time & Memory) بهێنە پاراستن.
    3. دا کۆدێ مە جوانتر، خواندەڤانتر و بساناهیتر بیت بۆ پاراستنێ (Readable & Maintainable).
int myNum = 5;              // ژمارا ساخ (Integer)
float floatVar = 10.2f;     // ژمارا ب فاریزە (پێدڤی ب پیتا fـە)
char myLetter = 'D';        // ئێک پیت د ناڤ تاکە کۆما ' ' دا
bool myBool = true;         // راست یان خەلەت (Boolean)
string myText = "Kurdistan";// نڤیسین د ناڤ جوت کۆما " " دا

ئەنجام: 20 centuries is 2000 years, or 730480 days, or 17531520 hours.

جۆرێن Boolean و Char و String

📌 سڵاید ٩: Boolean (bool)

  • بتنێ دوو بها هەنە: true و false. بهایێ بنەرەتی (Default): false.
  • د ئەنجامێ Console.WriteLine دا پیتا ئێکێ ب مەزنی دەردکەڤیت (True / False).
int a = 1, b = 2;
bool greaterAB = (a > b);
Console.WriteLine(greaterAB); // False
bool equalA1 = (a == 1);
Console.WriteLine(equalA1);   // True

📌 سڵاید ١٠: Character (char)

  • بتنێ ئێک پیت دهەلگریت د ناڤ تاکە کۆما ' ' دا (وەک 'B').
  • بهایێ بنەرەتی (Default): '\0'.

📌 سڵاید ١١: String (string)

  • نڤیسین (زنجیرەکا پیتان) د ناڤ جوت کۆما " " دا.
  • بهایێ بنەرەتی (Default): null (بێ بها).
  • دکاری ب نیشانا + دوو stringـان پێکڤە گرێبدەی، و نیشانا \n دێڕەکا نوو چێدکەت.
string firstName = "Dareen";
string lastName = "Muhammed";
Console.WriteLine("Hello, {0}!\n", firstName);
string fullName = firstName + " " + lastName;
Console.WriteLine("Your full name is {0}.", fullName);
/* ئەنجام:
Hello, Dareen!

Your full name is Dareen Muhammed. */
🎯 پسیارا سەر سڵاید ٩-١١:
ئایا char x = "A"; دروستە د C# دا؟
بەرسڤ: نەخێر خەلەتە! چونکی بۆ char دڤێت تاکە کۆما بهێتە بکارئینان: char x = 'A'; (جوت کۆما " " بتنێ بۆ stringـە).

📌 سڵاید ١٣ و ١٤: ئۆپەرەیتەرێن حسابی و نهێنیێن ئەزموونێ!

  • 11 / 3 چونکی هەردوو intـن، پاشماوێ پشتی فاریزێ دهاڤێژیت -> ئەنجام 3ـە!
  • 17 / 4.0 چونکی 4.0 جۆرێ doubleـە -> ئەنجام 4.25ـە!
  • 11 % 3 یانی ماوێ دابەشکرنا ١١ ل سەر ٣ -> ئەنجام 2ـە!
  • b++ (Post-increment): پێشییێ بهایێ کەڤن بکاردئینیت، پاشی ١ زێدە دکەت.
  • ++b (Pre-increment): پێشییێ ١ زێدە دکەت، پاشی بهایێ نوو بکاردئینیت.
int a = 5, b = 4;
Console.WriteLine(a + b);     // 9
Console.WriteLine(a + b++);   // 9  (پێشییێ 5+4=9 پاشی b دبیتە 5)
Console.WriteLine(a + b);     // 10 (چونکی b بوو 5)
Console.WriteLine(a + (++b)); // 11 (پێشییێ b دبیتە 6 پاشی 5+6=11)
Console.WriteLine(a + b);     // 11

📌 سڵاید ١٥، ١٦، ١٧، ١٨: ئۆپەرەیتەرێن بها دانانێ (Assignment)

کورتکرنا کریارانە، بۆ نموونە c += a یانی c = c + a. ئەڤە ئەنجامێن تەمام یێن سڵاید ١٦نە (چونکی ل سڵایدی ئەنجام نەهاتبوونە نڤیسین):

int a = 21, c;
c = a;    // Line 1: 21
c += a;   // Line 2: 21 + 21 = 42
c -= a;   // Line 3: 42 - 21 = 21
c *= a;   // Line 4: 21 * 21 = 441
c /= a;   // Line 5: 441 / 21 = 21
c = 200;
c %= a;   // Line 6: 200 % 21 = 11  (چونکی 21*9 = 189، ماوە 11ـە)
c <<= 2;  // Line 7: 11 * 4 = 44
c >>= 2;  // Line 8: 44 / 4 = 11
c &= 2;   // Line 9: 1011 & 0010 = 0010 = 2
c ^= 2;   // Line 10: 0010 ^ 0010 = 0000 = 0
c |= 2;   // Line 11: 0000 | 0010 = 0010 = 2
🚨 هشیاربوون ل سڵاید ١٨: د سڵاید ١٨ دا مامۆستای دوو جاران int y = 4; و پاشی int y = 3; نڤیسییە. د C# دا دوو جاران ناساندنا هەمان ناڤ ب int خەلەتییە (دڤێت دێڕا دووێ بێ int بیت: y = 3;). ئەنجامێن سڵاید ١٨ ئەڤەنە: 8, 3, 9, 6, 3, 9.
🎯 پسیارا سەر سڵاید ١٢-١٨:
ئەنجامێ ئەڤی کۆدی چییە؟ int x = 10; Console.WriteLine(x++ + ++x);
بەرسڤ: 22!
روونکرن: پێشییێ x++ بهایێ 10 ددەت و x دبیتە 11. پاشی ++x ژ 11 دکەتە 12. ئەنجام: 10 + 12 = 22.
سڵاید ١٩ تا ٢٢

ئۆپەرەیتەرێن بەراوردکاری و لۆجیکی (Comparison & Logical)

📌 سڵاید ١٩ و ٢٠: بەراوردکاری (== != > < >= <=)

ئەنجامێ وان هەردەم True یان Falseـە.

int a = 5, b = 4;
Console.WriteLine(a >= b);   // True
Console.WriteLine(a != b);   // True
Console.WriteLine(a == b);   // False
Console.WriteLine(a != ++b); // False (پێشییێ b دبیتە 5، پاشی 5 != 5 خەلەتە)
Console.WriteLine(a > b);    // False (5 > 5 خەلەتە)

📌 سڵاید ٢١ و ٢٢: لۆجیکی (&& || ^ !)

  • && (AND): بتنێ دەمێ هەردوو True بن ئەنجام Trueـە.
  • || (OR): ئەگەر ئێک ژ وان True بیت ئەنجام Trueـە.
  • ! (NOT): ئەنجامی بەرۆڤاژی دکەت.
  • ^ (XOR): بتنێ دەمێ ژێک جودا بن (ئێک True و ئێک False) ئەنجام Trueـە! ئەگەر وەکی ئێک بن -> False.
bool a = true, b = false;
Console.WriteLine(a && b);  // False
Console.WriteLine(a || b);  // True
Console.WriteLine(a ^ b);   // True (ژێک جودانە)
Console.WriteLine(!b);      // True
Console.WriteLine((5 > 7) ^ (a == b)); // False ^ False -> False
🎯 پسیارا سەر سڵاید ١٩-٢٢:
ئەنجامێ ئەڤێ چییە؟ !(10 > 5) || (3 == 3 && 4 < 2)
بەرسڤ: False!
روونکرن: !(True) دبیتە False. لایێ دی: (True && False) دبیتە False. کەواتە False || False = False.
سڵاید ٢٣ تا ٢٦

ئۆپەرەیتەرێن بت-ب-بت و یێن دی (Bitwise & Other Operators)

📌 سڵاید ٢٣ و ٢٤: Bitwise Operators (بت ب بت)

ل سەر ژمارێن ساخ (byte, sbyte, int, uint, long, ulong) د سیستەمێ Binary (0 و 1) دا کار دکەن:

ushort a = 3; // 00000000 00000011
ushort b = 5; // 00000000 00000101
Console.WriteLine(a | b);  // 00000111 = 7  (ئەگەر ئێک ژی 1 بیت -> 1)
Console.WriteLine(a & b);  // 00000001 = 1  (بتنێ 1 & 1 -> 1)
Console.WriteLine(a ^ b);  // 00000110 = 6  (ئەگەر ژێک جودا بن -> 1)
Console.WriteLine(~a & b); // 1100 & 0101 = 0100 = 4
Console.WriteLine(a << 1); // 00000110 = 6  (بۆ چەپێ = جارانی 2)
Console.WriteLine(a >> 1); // 00000001 = 1  (بۆ راستێ = دابەشی 2)

📌 سڵاید ٢٥ و ٢٦: گرێدانا String و ئۆپەرەیتەرێ مەرجی (?:)

  • لێکدانا String + ژمارە (سڵاید ٢٥): "The number is : " + 5 ئۆتۆماتیکی ژمارێ دکەتە string و دبیتە "The number is : 5".
  • ئۆپەرەیتەرێ مەرجی ?: (سڵاید ٢٦): condition ? ifTrue : ifFalse
  • new (دروستکرنا ئۆبجێکتی)، typeof (زڤراندنا System.Type)، is (پشکنینا گونجانا جۆری).
int x = 20, y = 10;
var result = x > y ? "x is greater than y" : "x is less than y";
Console.WriteLine(result); // x is greater than y
🎯 پسیارا سەر سڵاید ٢٣-٢٦:
ئەنجامێ 4 << 2 چەندە؟
بەرسڤ: 16!
روونکرن: دوو جاران خشاندن بۆ چەپێ یانی دوو جاران جارانی ٢: 4 × 2 × 2 = 16 (یان د باینەری دا 00100 دبیتە 10000).
سڵاید ٢٧ تا ٢٩

Type Casting و Type Conversion و Expressions

📌 سڵاید ٢٧: Type Casting (گوهۆڕینا جۆرێ داتایان)

  1. Implicit Casting (ئۆتۆماتیکی): ژ جۆرەکێ بچیک بۆ جۆرەکێ مەزنتر (بێ خەتەر):
    char -> int -> long -> float -> double
  2. Explicit Casting (ب دەست): ژ جۆرەکێ مەزنتر بۆ جۆرەکێ بچیکتر (ب رێکا کڤانێن ( )):
    double -> float -> long -> int -> char 
int myInt = 9;
double myDouble = myInt;         // Implicit: 9

double d2 = 9.78;
int i2 = (int) d2;               // Explicit: 9 (پشتی فاریزێ دبرێت، نابیتە 10!)

📌 سڵاید ٢٨: Type Conversion (مێسۆدێن Convert)

فەرمانێن حازر: Convert.ToBoolean، Convert.ToDouble، Convert.ToString، Convert.ToInt32 (بۆ int)، Convert.ToInt64 (بۆ long).

📌 سڵاید ٢٩: Expressions (دەربڕین)

دەربڕین زنجیرەیەکە ژ ئۆپەرەیتەر و بها و گوهۆڕان، و هەر دەربڕینەکێ دوو تشت هەنە: Type (جۆر) و Value (بها).

int r = (150 - 20) / 2 + 5; // 130 / 2 + 5 = 65 + 5 = 70

int a = 2 + 3;            // a = 5
int b = (a+3) * (a-4) + (2*a + 7) / 4;
// = 8 * 1 + 17 / 4 = 8 + 4 = 12 (هشیار بە 17/4 = 4ـە نە 4.25!)
bool g = (a > b) || ((a == 0) && (b == 0));
// = false || (false && false) = False
🎯 پسیارا سەر سڵاید ٢٧-٢٩:
جیاوازییا دەرئەنجامێ (int) 9.78 چییە و ئایا نێزیکی 10 دکەت؟
بەرسڤ: نەخێر نێزیک ناکەت؛ ئەنجام هەر 9ـە چونکی Explicit Casting بتنێ بەشێ پشتی فاریزێ ژێدبەت (Truncate).

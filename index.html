C# چییە؟ (What is C#?) سلاێدێ ٣
  • بلەفکرن (Pronunciation): دبێژنێ "C-Sharp" یان ژی "C-Hash".
  • جۆرێ زمانێ بەرنامەسازیێ: زمانەکێ Object-Oriented (تەوەر-کائن) یە.
  • دروستکەر: ژ لایێ کۆمپانییا Microsoft هاتیە بەرهەمئینان.

  • ڕەچەلەک: ڕەهێن وی دزڤڕنەڤە بۆ بنەماڵا C، و گەلەکێ نێزیکی زمانێن C++ و Java یە.
  • مێژوو: ئێکەم ڤێرژن ل سالا 2002 هاتیە بەلاڤکرن.

بکارهێنان و گرنگیا C# (Applications & Advantages) سلاێدێ ٤ و ٥

بکارهێنانێن C# (C# Applications):

C# بۆ دروستکرنا ڤان تشتا دهێتە بکارئینان:

  • Mobile applications (بەرنامەیێن مۆبایلێ).
  • Desktop applications (بەرنامەیێن کۆمپیۆتەر و ویندۆز).
  • Web applications & Web services (بەرنامە و خزمەتگوزاریێن وێبێ).
  • Web sites (ماڵپەڕێن ئینتەرنێتێ).
  • Games (یاریێن ڤیدیۆیی - ب تایبەت ل سەر Unity).
  • VR (Virtual Reality - ڕاستیا خەیالی).
  • Database applications (بەرنامەیێن داتابەیسێ).

بۆچی C# بکاربینین؟ (Why Use C#?):

  • ئێک ژ بەربلاڤترین و بەناوبانگترین زمانێن جیهانێ یە.
  • فێربوونا وی یا ب ساناهییە و بسادەیی دهێتە بکارئینان.
  • کۆمەڵگەهەکا مەزن یا پشتەڤانیێ هەیە (Huge Community Support).
  • ژبەرکو Object-Orientedە، ڕێکخستنەکا زەلال ددەتە پڕۆگرامی و دبیتە ئەگەرێ دووبارە بکارهێنانا کۆدی (Code Reuse) کو تێچوویێ دروستکرنێ کێم دکەت.
  • ژبەرکو نێزیکی C, C++ و Javaیە، گوهۆڕین دناڤبەرا واندا گەلەک یا بساناهییە بۆ پرۆگرامەری.
پەیکەرێ گشتی یێ کۆدی (C# General Syntax) سلاێدێ ٦ و ٧

هەر کۆدەکێ بنەڕەتی یێ C# ب ڤی شێوەیێ ل خوارێ دهێتە نڤیسین:

using System;

namespace test
{
    class Program
    {
        static void Main(string[] args)
        {
            // C# statements...
        }
    }
}

شروڤەکرنا پشکێن کۆدی ب بادینی:

  • using System; : مەبەست ژێ ئەوە کو ئەم دشێین کلاس و کەرەستەیان ژ کتێبخانە و ناڤناڤێ (System Namespace) بکاربینین.
  • namespace test : هێلانە یان کانتینەرەکە بۆ ڕێکخستنا کۆدێ تە و پاراستنا ناڤێن کلاسان.
  • { } کەوانێن خوار (Curly Braces) : دەستپێک و دوماهیا هەر بلۆکەکێ کۆدی دیار دکەن.
  • class Program : کانتینەرەکە بۆ دانانا داتا و مێتۆدان. هەر دێرەکا کۆدی د C# دا دڤێت د ناڤ کلاسی دا بیت.
  • static void Main(string[] args) : ئەڤە ناڤێ وێ Main Method ە. جێبەجێکرنا هەمی پڕۆگرامان د C# دا هەردەم ل ڤێرێ دەستپێدکەت.
ئێکەم نموونە و تێبینیێن زێڕین (First Example & General Notes) سلاێدێ ٨ و ٩ 
using System;
namespace test
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello World!");
        }
    }
}

دەرئەنجام (Output): دەقێ Hello World! ل سەر شاشەی دهێتە چاپکرن.

🔥 تێبینیێن گشتی یێن ئەزموونێ (General Notes - گرنگترین پشک):
  • C# is Case sensitive: زمانەکێ گەلەک هەستیارە ل سەر پیتێن مەزن و بچویک! پیتا a نە وەکی A یە.
  • Semicolon (;): پێدڤیە هەمی دەستەواژە و فەرمان ب فاریزەیا خالدار (;) ب دوماهیک بهێن.
  • Execution: بەرنامە هەردەم دەست ب کار دکەت ل مێتۆدا Main.
  • Unlike Java: بەپێچەوانەی زمانی جافا، ناڤێ فایلی مەرج نینە وەکی ناڤێ کلاسی بیت.
  • Console.ReadKey(): ل داویا بەرنامەی دهێتە دانان دا شاشە ڕاوەستیت و ئێکسەر نەهێتە گرتن هەتا تو کلیلیەکا کیبۆردی دادگری.
جوداهیا دناڤبەرا WriteLine() و Write() سلاێدێ ١٠
  • Console.WriteLine(): دەقی چاپ دکەت، و پاشی کورسەری دبەتە دێرەکا نوی (New Line) بۆ چاپی داهاتی.
  • Console.Write(): دەقی چاپ دکەت، لێ ل سەر هەمان دێر دمینیت و ناچیتە دێرەکا نوی.
Console.WriteLine("Hello World!");
Console.WriteLine("I will print on a new line.");
Console.Write("Hello World! ");
Console.Write("I will print on the same line.");

دەرئەنجام (Output):

Hello World!
I will print on a new line.
Hello World! I will print on the same line.
تێبینی د کۆدی دا (C# Comments) سلاێدێ ١١

تێبینی ژ بۆ ڕوونکردنا کۆدی یە و کۆمپایلەر وان ناخوینیت (ناهێنە جێبەجێکرن):

  • تێبینیا ئێک دێر (Single-line comment): ب دوو سلاشان دەستپێدکەت //
  • تێبینیا چەند دێران (Multi-line comment): ب /* دەستپێدکەت و ب */ بدوماهیک دهێت.
// ئەڤە تێبینیا ئێک دێرە
Console.WriteLine("Hello World!"); // ئەڤە ژی دێرەکا دی یە

/* ئەڤ کۆدێ ل خوارێ
دەقێ Hello World چاپ دکەت
و چەند دێرن */
Console.WriteLine("Hello World!");
گۆڕاوەکان و جۆرێن وان (C# Variables & Data Types) سلاێدێ ١٢، ١٣، ١٤

گۆڕاو (Variable): کانتینەر و سندوقەکە بۆ هەلگرتنا بهایێن داتایێ د ناڤ بیرگەهێ دا.

شێوازێ دروستکرنێ (Syntax): type variableName = value;

جۆرێ داتایێ (Type) شروڤەکرن ب بادینی نموونە تێبینیا تایبەت
int ژمارەیێن دروست (بێ فاریزە) int x = 123; موجب و سالب قەبیل دکەت
double ژمارەیێن فاریزەدار (دەشاڕی) double d = 19.99; دشێی پیتا D ژی ل داویێ دانی
char بتنێ ئێک کاراکتەر یان پیت char c = 'a'; دڤێت د ناڤ کەوانێ تاک بیت ' '
string دەق و پەیڤێن درێژ string s = "Hello"; دڤێت د ناڤ جووت کەوانان بیت " "
bool بهایێن لۆژیکی: ڕاست یان شاش bool b = true; بتنێ true یان false

یاسایێن گۆڕاوان (Declaration vs Initialization):

int age;       // Declaration (بتنێ ناساندن)
age = 25;      // Initialization (دانانا بهایی بۆ ئێکەم جار)

age = 20;      // Overwriting (بهایێ کەڤن لادبەت و دبیتە 20)
❌ خەلەتیا بەربلاڤا ئەزموونێ (Compile-time Error):
نابیت متغیرەکی بکاربینی بەری بهای بدەیێ! ئەگەر بنڤیسی: 
int age;
int j = age; // ERROR: Use of unassigned local variable 'age'
ئەڤە خەلەتیە چونکی `age` چ بها د ناڤدا نینە!
نەگۆڕەکان (Constants - const) سلاێدێ ١٥

ئەگەر تە نەڤێت کەس بشێت بهایێ گۆڕاوەکێ بگوهۆڕیت، پەیڤا const ل دەستپێکێ دانی. ئەڤ بها دێ بیتە نەگۆڕ و بتنێ بۆ خواندنێ یە (read-only).

const int age = 25;
age = 30; // ❌ ERROR: The left-hand side of an assignment must be a variable...
⚠️ یاسایا نەگۆڕان: نابی نەگۆڕەکی دروست بکەی بێی کو دەستبەجێ بهای بدەیێ!
const int myNum; ❌ ئەڤە خەلەتە! (A const field requires a value to be provided).
نیشاندانا گۆڕاوان و هێمایێ کۆمکرنێ (+) سلاێدێ ١٦ و ١٧

هێمایێ + د ناڤبەرا دوو کاران دا دهێتە بکارهێنان:

  • پێکڤەگرێدان (Concatenation): ئەگەر دگەل دەقان (String) بیت، پەیڤان دنیسکینیتە ئێک:
string firstName = "Salar ";
string lastName = "Raman";
string fullName = firstName + lastName;
Console.WriteLine(fullName); // دێ بیژیت: Salar Raman
  • کۆمکرنا بیرکاریێ (Mathematical Addition): ئەگەر دگەل ژمارەیان بیت (وەک int)، کۆم دکەت:
int x = 10;
int y = 5;
Console.WriteLine(x + y); // دەرئەنجام: 15

دروستکرنا چەندین گۆڕاوان ب ئێک دێر (ب بکارئینانا فاریزێ):

int x = 5, y = 6, z = 50;
Console.WriteLine(x + y + z); // دەرئەنجام: 61
پەیڤێن تایبەت و یاسایێن ناڤلێنانێ (Keywords & Identifiers) سلاێدێ ١٨ و ١٩

پەیڤێن تایبەت (Keywords):

ئەڤە پەیڤێن قەدەغەکرینە کو تایبەتن ب کۆمپایلەرێ C# ڤە، وەک: class, int, double, const, static, void, bool, for, if.

💡 فێڵا کویزی: ئەرێ دشێین پەیڤەکا تایبەت بکەینە ناڤێ متغیری؟
بەلێ! بتنێ ئەگەر هێمایێ @ بەری وێ پەیڤێ دانی. بۆ نموونە: int @class = 10; (دروستە!).

یاسایێن ناڤلێنانێ (Identifiers Rules):

  • هەمی ناڤ پێدڤیە ب پیت یان هێمایێ ئەندەرسکۆر ( _ ) دەستپێبکەن.
  • ب چ شێوەیان نابیت ب ژمارە دەستپێبکەت! (بۆ نموونە: 1name ❌ خەلەتە، بەس name1 ✅ دروستە).
  • نابیت بۆشایی (Space) د ناڤبەرا ناڤی دا هەبیت (my age ❌ خەلەتە، myAge ✅ دروستە).
  • پیتێن مەزن و بچویک جودانە (Case sensitive) بۆ نموونە: myVar و myvar دوو ناڤێن جودانە.
  • نابیت پەیڤێن تایبەت (Keywords) بهێنە بکارئینان (مەگەر ب @ دەستپێبکەت).

خەلەتی: بهایێ bool نابیت د ناڤ دوو کەوانان بیت، دڤێت بنڤیسی: bool isPass = true; .
